# 界面导览

主窗口的三个区域，以及不属于任何页面、浮在所有页面之上的组件。

主窗口分三部分：左侧侧边栏、顶部标签页、中间内容区。窗口最小 1024 × 640。

![主窗口：左侧边栏、顶部标签页、中间内容区](/shots/home-projects.png)

## 侧边栏

自上而下：品牌区、功能入口、「更多」、AI 对话列表，最下面是齿轮图标加版本号（点击进入偏好设置）。版本号右边是更新角标，有新版本时显示，见[安装与更新](/guide/install#更新)。

### 功能入口

默认常驻四项：项目库、资产库、蓝图库、材质库。

其余功能（知识库、AI 创作）收在「更多」中。点击「更多」在右侧展开浮层，点击浮层外区域收起。当前页面属于「更多」中的功能时，触发行高亮，但浮层不自动展开。3D 查看器和笔记在侧边栏没有入口。

### 自定义常驻项

「更多」浮层内的「自定义」：

- 勾选的功能常驻侧边栏，未勾选的收入「更多」
- 拖动调整顺序
- 点「完成」保存

### AI 对话列表

侧边栏下半部分，分三段：

| 段       | 内容                 |
| -------- | -------------------- |
| **置顶** | 已置顶的对话         |
| **项目** | 按 UE 工程分组的对话 |
| **对话** | 未关联 UE 工程的对话 |

对话行显示状态标记：**已连接**、**正在运行**、**有待回答的问题**、**任务已完成，未查看**。后两者表示这条对话需要你处理。

**整理侧边栏**（列表顶部）提供两组选项：

- 分组方式：按 UE 工程 / 在一个列表中
- 排序：最近更新 / 创建时间 / 名称

**对话行的菜单**：置顶、归档、在新窗口打开、重命名（弹窗里有「智能命名」，按整段对话起标题）、归入工程、不在项目中工作、新建工程分组、删除。

**多选**：`Ctrl`（macOS `Cmd`）+ 点击逐条加选，`Shift` + 点击选择连续范围，之后可批量删除。

**项目分组的菜单**：置顶、重命名项目、在资源管理器中打开、归档对话、移除项目。

- **归档对话** 将该工程下的所有对话归档，之后在 设置 → AI 助手 → 归档对话 中查看和恢复。
- **移除项目** 仅将分组从侧边栏移除，其中的对话不删除，回到「对话」段。

**添加项目**分组有两种来源：选择本机的 UE 工程目录，或从已导入的工程中选择。

**同名工程**：同一台机器上有两个同名工程（例如复制了一份）时，侧边栏按路径拆成两个分组。新建对话和选择工程时，同名项会带上路径区分。名字只出现一次时仍按名字归组。

### 收起与浮出

侧边栏可以收起。收起状态下鼠标移至左边缘时临时浮出，移开后收回。

拖动侧边栏边缘调整宽度，双击边缘恢复默认宽度。

## 标签页

每打开一个页面新增一个标签。

右键标签：关闭、关闭其他、关闭右侧、固定（取消固定）。固定的标签不受「关闭其他」影响。对话标签另有「在新窗口打开」。

标签会持久化。重新打开应用时回到上次所在的标签；没有保留的标签时进入项目库。

## 切页面也不会消失的东西

以下组件挂在应用层，不属于任何一个页面，切换页面后仍然显示。Agent 在后台干活时，你需要能随时看到这些状态。

| 组件               | 出现条件                                                                                                       |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| **导入进度**       | 资产导入进行中。点击卡片跳转到对应文件夹，也可中止                                                             |
| **资产锁指示器**   | Agent 锁定资产时，显示「AI 锁定了 N 个资产」，可全部解锁                                                       |
| **敏感操作确认**   | Agent 请求执行需要确认的操作时。卡片上可选「本对话内均允许」「以后均允许」，后者在 设置 → AI 助手 里可逐项移除 |
| **引擎桥接横幅**   | 桥接不可用时                                                                                                   |
| **全局音频播放器** | 播放生成的音频或朗读回复时                                                                                     |

资产库页面底部另有一条状态栏，仅在该页面显示。

## 主题

设置 → 外观：跟随系统 / 浅色 / 深色 / 自定义。自定义模式可设置主色、辅色、强调色，设置时校验对比度，过低时提示，但仍可应用。

「减少动态效果」三档：跟随系统 / 开启动效 / 减少动效。

## 独立窗口

以下界面运行在独立窗口中，不在主窗口内：

| 窗口         | 打开方式                                                   |
| ------------ | ---------------------------------------------------------- |
| AI 对话      | 把对话拖出主窗口，或右键「在新窗口打开」，见下节           |
| 快捷提问     | 全局快捷键，见 [Spotlight](/guide/spotlight)               |
| 快捷问答小窗 | 快捷提问的「与 AI 对话」、`Ctrl+Shift+M`、或「侧边问一句」 |
| 快速录制窗   | 从蓝图库/材质库「录制封面」或资产库详情面板打开            |
| 区域选择遮罩 | 录制选区时                                                 |
| Agent 浏览器 | 浏览器显示方式设为「独立窗口」时                           |

### AI 对话的独立窗口

一条对话可以单独放进一个窗口，主窗口继续做别的事。三种打开方式：

- 把对话标签拖出标签栏
- 把侧边栏里的对话拖到右侧内容区或窗口外再松手（在列表里来回拖动不会弹窗）
- 右键标签或侧边栏对话行 →「在新窗口打开」

独立窗口的行为：

- 只放这一条对话，主窗口里的标签会摘掉。主窗口再打开这条对话时，会把已拖出的窗口提到前面
- 两个窗口实时同步。对话记录只由主窗口写入磁盘
- 窗口内可以直接用 Agent 内嵌浏览器和语音通话。通话在哪个窗口开始就归哪个窗口，后开的窗口接手，先开的窗口提示「语音通话已转到另一个窗口。」
- 关窗口时如果这条对话还有一轮在运行，窗口先隐藏，跑完再真正关闭

## 系统托盘

点主窗口的关闭按钮只会把窗口隐藏到托盘，盒子继续在后台运行；真正退出要用托盘菜单的「退出」。托盘菜单：

| 菜单项           | 作用                                                                          |
| ---------------- | ----------------------------------------------------------------------------- |
| **新对话**       | 拉起主窗口并新建一条对话                                                      |
| **最近对话**     | 按最后活跃时间列出前 3 条，不含归档对话和嵌在页面里的对话，点击直接跳到该对话 |
| **最近项目**     | 虚幻引擎最近打开过、且已导入项目库的工程，最多 3 条，点击打开                 |
| **打开虚幻盒子** | 显示主窗口                                                                    |
| **退出**         | 退出应用                                                                      |

最近项目里，已连上的工程标「（运行中）」，刚点击打开、插件还没连上的标「（启动中）」，这两种不能再点，避免开出第二个编辑器。点击后工程打不开、已经开着、或插件没装上，托盘会弹系统通知说明原因。

退出，或安装更新时，如果 AI 还有操作没做完，会弹出确认框「AI 仍有 N 项操作正在进行，退出将中断这些操作。」，可以选「仍然退出」（安装更新时是「仍然重启安装」）或取消。

设置 → 项目库 →「打开工程后隐藏主界面」开启后，打开工程时主界面自动收到托盘，后台任务继续运行。
