# AI 创作（生图）

生成概念图、贴图、UI 草图和参考图，结果保存进 AIGC 资产库。

侧边栏「更多」里的 **AI 创作**。左侧是参数面板，右侧是生成历史。

![AI 创作](/shots/aigc-studio.png)

3D 模型生成是另一条路，见 [3D 生成与查看器](/guide/model3d)。

## 配置

**设置 → 模型 → 添加服务商 →「图片生成」分组**，挑一家填密钥。确认那个模型勾了「**生图**」能力，再到「默认模型 → 生图」指向它。

没配好时页面显示「暂无可用的生图模型」，带「配置模型」按钮。面板顶部显示当前模型（来自 设置 → 模型 的「生图」角色），旁边可以「切换」。

## 文生图与图生图

**不加参考图**：文生图，填「描述」。例如：

> 一只可爱的柴犬坐在樱花树下，水彩画风格，高清细节。

**加了参考图**：图生图，「描述」变成「**编辑指令**」。例如：

> 保留主体和服装，把背景改成雨夜街道，电影感光影，突出人物。

### 参考图的三种来源

1. 拖进去
2. **Ctrl + V 粘贴**（面板上直接提示了这一条）
3. 点「**参考库**」

参考库读取 AIGC 资产库中的固定目录，界面显示还能添加几张。目录为空时提示把图片放进 `AIGC 资产库 / <目录名>`，并提供「打开参考素材库」入口。

资产库里的图片也能右键「**用作参考图生成**」送过来。

参考图满了会提示「参考图最多 N 张」。

## 参数

### 宽高比与尺寸

有一排常用比例，点「更多比例」展开全部。

### 分辨率

可选项随模型变，面板下方会写明这个模型支持什么：

| 档位 | 说明                   |
| ---- | ---------------------- |
| 1K   | 更快出图，快速查看效果 |
| 2K   | 画质与速度更平衡       |
| 4K   | 高细节，适合最终成图   |
| Auto | 模型自动选择尺寸       |

有些模型走的是具体尺寸而不是档位：方图 1024（速度最快）、横图 1536×1024、竖图 1024×1536、2K 方图 2048、2K 横屏 2048×1152、4K 横屏 3840×2160、4K 竖屏 2160×3840。

### 质量

Auto / 低 / 中 / 高。低档更快，适合草图验证；高档细节更多。

::: warning 部分模型按质量档位计费
面板会提示「GPT Image 2 使用质量档位计费」这类说明。调高档位直接对应更高的花费。
:::

### 生成数量

支持一次生成多张，也可填写自定义数量。批量提交时任务间隔 1.7 秒依次发出，提示「已提交 N 个任务，间隔 1.7 秒」；有失败时提示「已提交 X 个，Y 个失败」。

### 负面提示词与高级参数

在「高级参数」里。

## 优化提示词

「优化提示词」由模型重写描述。存在参考图时会**结合参考图**优化，并提示「已根据参考图优化提示词」。

![提交之后：中间是进度，右侧历史里那一条显示「生成中」](/shots/aigc-generating.png)

## 生成历史

右侧整块是历史，按时间分组（今天 / 昨天 / N 天前 / 具体日期 / 更早）。

![生成完成：左边参数、中间大图、右边历史](/shots/aigc-result.png)

**筛选**：全部 / 进行中 / 已完成 / 失败。

**搜索**：按提示词、模型、风格搜。

**排序与视图**：最新优先 / 最早优先，画廊模式 / 列表模式。

每张卡片显示状态（排队中 / 生成中 N% / 已完成 / 失败）、张数、参考图数量和相对时间。

**清除失败** 会删掉失败记录，**已生成的资产不会被删除**。

## 对一张图能做什么

大图预览的顶部工具栏和历史卡片的「⋯」是同一套操作：

| 操作           | 说明                                     |
| -------------- | ---------------------------------------- |
| 用作参考图     | 作为下一轮的参考图                       |
| 复制图片       | 到剪贴板                                 |
| 下载图片       |                                          |
| **回填参数**   | 把这次的参数回填到左侧表单，在此基础上改 |
| 复制提示词     |                                          |
| 在资产库中定位 | 在 AIGC 资产库中定位这张图               |
| 删除记录       |                                          |

::: tip 删除记录不删图
删除记录无法恢复，已保存进资产库的图片不受影响。
:::

## 生成的图存在哪

保存在 **AIGC 资产库**。历史面板顶部有「打开资产库」。找不到那个库时提示「找不到 AIGC 资产库」。

## 助手也能生图

在 AI 对话里直接说要什么图，或者点输入框的「**图片生成**」进入生图模式。两种方式用同一个「生图」默认模型。

助手还可以把 UE 里的白盒截图当参考图，让模型画成概念图，见[白盒出概念图](/guide/capabilities#镜头与成片)。

::: tip 重做需要用户确认
生图按次计费，结果是否符合预期由你判断。助手认为结果不理想时会询问你，不会自行重新生成。
:::

## 助手还能生成的其他素材

下面几项没有独立页面，在 AI 对话里用自己的话要求，对应的默认模型在 **设置 → 模型 → 默认模型**：

| 素材       | 默认模型 | 说明                                                                 |
| ---------- | -------- | -------------------------------------------------------------------- |
| 3D 模型    | 3D 生成  | 见 [3D 生成与查看器](/guide/model3d)                                 |
| 视频       | 视频生成 | 文字或参考图生成视频，可能需要数分钟，失败也可能扣费                 |
| 配乐       | 音乐生成 | `generate_task_music` 生成纯音乐并存进资产库；未配置时视频不自动配乐 |
| 台词、旁白 | 语音合成 | `generate_speech` 把文字合成为 WAV。视频旁白用同一条合成             |

生成的音乐和 3D 模型显示在助手回复里生成它的那组步骤下面。外部 MCP 客户端（如 Claude Code）调用时不需要盒子里的对话，也能单独生成配乐和配音，见 [MCP](/guide/mcp#外部客户端能用什么)。
