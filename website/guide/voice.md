# 语音通话

用语音代替打字与助手交互。

通话由两部分配合：

- **语音模型**：听你说话、回答只读查询、念进度。
- **后台 Agent**：执行会改动工程的任务，规划、工具权限、确认、撤销栈都在这一侧。

下面的行为大多由这个分工决定。

## 配置

**设置 → 模型 → 默认模型 → 实时语音**。

支持 OpenAI 的 `gpt-realtime` 系列和豆包 Seeduplex，普通对话模型不能绑在这里。

### 不绑实时语音也能通话

「实时语音」留空，但「语音识别」「语音合成」都配好了，通话改由对话模型应答：识别出一句话，交给输入框当前选的模型回答（思考自动关闭），回答逐句合成念出来。派活、反问、审批照常。

| 和实时语音比 | 说明                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 慢           | 要等识别、模型首字、合成首包三段，一句话通常多等几秒。思考已自动关闭，快慢主要看「轻量任务」模型本身                           |
| 播报逐字念   | 任务完成的通知原话念出，不经模型转述                                                                                           |
| 插话先停后判 | 它说话时有声音先停播；识别模型说那不是人声，或「结构化判定」模型判断只是附和、杂音、回声，就接着说。没配判定模型时有字就算插话 |

语音识别可以用本机运行的 SenseVoice、Whisper 等服务，见 [Spotlight 的语音下指令](/guide/spotlight#语音下指令)；语音合成可以用本机的 Kokoro、CosyVoice 等 OpenAI 兼容服务（添加服务商 →「本机语音合成」）。两样都放本机时，只有对话模型走网络。

音色在「模型」页设置（模型设置里的「语音音色」），保存后下次通话生效，当前通话不会中途换音色。

**语音合成（TTS）** 用于朗读助手的文字回复，走另一个默认模型。两项可以只配置其中一项。

### 麦克风与回声抑制

**设置 → 语音**：

| 项       | 说明                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| 麦克风   | 默认系统设备，也可指定一个。下次通话生效                                     |
| 回声抑制 | 耳机（灵敏度最高）/ 外放（默认）/ 音箱很近（抑制最强，小音量语音可能被丢弃） |

![设置 → 语音](/shots/settings-voice.png)

提示「无法读取麦克风，请检查设备和权限」时，通常是系统没有授予麦克风权限。

## 开始通话

入口是输入框上的麦克风按钮「开始语音通话」。从哪里点，决定通话绑在哪条对话上：

| 从哪里点           | 绑在哪                                 |
| ------------------ | -------------------------------------- |
| 欢迎页             | 绑定眼前这条空对话，每次都是独立的一段 |
| 某条已有对话里     | 绑定这条：读它的上文，通话内容写进它   |
| 通话中点另一条的麦 | 不换绑，维持当前这通                   |

通话里说的第一句话会给这条对话起名（仅当标题还是占位符时）。

连接过程中输入框显示「正在连接语音…」，可以「取消连接」。超时提示「语音连接超时，请重试或检查实时语音模型设置」。

### 通话的边界

- 通话属于整个应用：切对话、切标签页、去资产库都不会断，只有你挂断或清空绑定的那条对话才结束。
- 空闲时连续三次无人回应，自动挂断（可在 设置 → 语音 → 语音助手 里关闭）。
- 单次通话最长 30 分钟，到时挂断，再点一次可接着聊。
- 对话可以拖出成独立窗口。通话开在哪个窗口就归哪个窗口；在另一个窗口再开通话，先开的那个窗口提示「语音通话已转到另一个窗口」。独立窗口里可以直接使用内嵌浏览器和语音。

## 它自己答什么，派给谁

**只读的快查它当场答**：已登记的工程、可以派活的对话、当前连着哪个编辑器、编辑器里选中了什么。

**会改工程的事都派给后台 Agent**，派发后立即返回，不等执行结果。所以听到「开始做了」之后可以继续说话。

::: warning 「开始做了」不等于「做完了」
派发的回执只是「已收到」。结果在做完时另外念给你。
:::

说「把这个调暗一点」而没给名字时，它先查看编辑器，说出名字请你确认，再按名字派活。

## 几件活同时跑

每件活被分到一条**任务线**（一个短名字，说明这件活在动哪个东西）。判断标准只有一条：会不会动到别的任务线正在动的东西。

| 情况                     | 结果                                      |
| ------------------------ | ----------------------------------------- |
| 动的是两个不同的东西     | 各占一条任务线，同时跑                    |
| 可能动到别人正在动的东西 | 排在那条任务线后面，告诉你「排在第 N 位」 |
| 接着改同一个东西         | 落到同一条，那条对话记得上一件做过什么    |
| 任务线已有 5 条还要再派  | 排到最久没用的那条后面，并告诉你          |

同时有多条任务线在跑时：

- 某一件做完，念出来时带上线名（「灯光那边，……」）。
- 问「做得怎么样了」，它报所有任务线的情况。
- 说「停下」，它先问你要停哪件，不自己猜。

::: tip 派活会另开一条任务对话
这通电话第一次派活时，会建一条对话「语音任务 · 这通的名字」，执行过程和结果都在那里。没派活就不建。
:::

## 说话之间

### 打断

默认全双工：它说话时麦克风不关，你直接开口就会打断它。它立刻停下，丢掉未念完的内容，**任务不停**。

不方便出声时，点界面上的球体，或在 设置 → 快捷键 →「打断语音助手」绑一个按键（默认未绑定）。

::: warning 半双工的两种情况
下面两种情况下麦克风被强制静音，只能靠快捷键或点球体打断：

- 本地朗读兜底通知时（这条路径不经过回声消除）。
- 回声消除通路建立失败时（`RTCPeerConnection` 不可用或被拦截）。

:::

外放时它听到自己的声音会被消掉（播放走 WebRTC 回环）。外放仍出现自问自答时，把回声抑制调到「音箱很近」。

### 改主意和喊停

| 你说的            | 会发生什么                                     |
| ----------------- | ---------------------------------------------- |
| 「等等，改成 XX」 | 插进正在跑的那一轮，不新开一件                 |
| 「停下」          | 停正在跑的那件，队里没开始的一起撤掉，并告诉你 |
| 「算了别做那件」  | 从队里撤掉，不播报                             |
| 「不用了，再见」  | 道别那句念完自动挂断；你又开口就不挂了         |

还有活在跑时说「再见」，它先说明在跑什么再问你。你确认后才挂断，活继续在后台跑完，下次开语音会告诉你结果。

### 暂停收音

输入框上的「暂停收音」暂停麦克风，**后台任务继续运行**。「结束语音通话」结束整通电话，任务同样继续跑。

## 反问与审批走语音

Agent 需要你决定时，语音把问题念出来：

- **选择题**：口头回答，原话交回给 Agent；说「你看着办」让它自己定。
- **高风险操作的审批**：口头表态。它不会替你批准；你含糊其辞或它没听清，一律按拒绝处理。「以后都行」这类长期授权，只在你明确说出口时才给。
- **你没等它念完，直接在界面上点了答案**：语音那条作废，不再念，任务继续。

## 挂断再接上

任务不受挂断影响。再开语音时，它先交代你不在期间发生的事：

| 不在线期间发生的         | 接上时                                 |
| ------------------------ | -------------------------------------- |
| 活做完了、失败了、卡住了 | 先念这些（同一件活同一类只留最新一条） |
| 反问或审批还没人答       | 再念一遍                               |
| 反问在界面上已被答掉     | 作废，不念                             |
| 还在跑的活               | 提一句最近一次汇报                     |
| 中途进度                 | 丢掉                                   |

一条都没有就不说。关闭语音时队里还排着活，下次开语音会自动接着跑。

## 自动朗读

**设置 → 语音 → 通用**：

| 项       | 说明                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 自动播放 | 对话生成结束后自动朗读回复。需要先配置「语音合成」模型                                                                       |
| 播报风格 | **简洁**：轻量模型压成三句以内（执行内容、结果、待办）；**详细**：提炼结论、关键步骤和待决定事项；**完整**：朗读原文，不压缩 |

单条回复也可以手动点朗读按钮。

## 汇报多少

**设置 → 语音 → 语音助手**：

| 项                     | 说明                             |
| ---------------------- | -------------------------------- |
| 助手反馈：简洁         | 只响应提问，不主动汇报进度       |
| 助手反馈：详细         | 长任务无反馈满一分钟时汇报进度   |
| 无人回应时自动结束通话 | 空闲时连续三次无人回应则结束通话 |

## 局限

- 语音层不做多步规划，也不直接执行写操作。规划、工具权限、确认、撤销栈都在 Agent 一侧。
- 能当场回答的只有固定名单里的只读查询，新增一项要显式加进去。
- 语音念出的每一句都会出现在这通电话绑定的对话里。
