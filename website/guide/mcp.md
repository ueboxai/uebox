# MCP

给助手接第三方 MCP 服务，或把盒子助手的工具开放给 Claude Code、Cursor 等外部客户端。

MCP（Model Context Protocol）是 AI 客户端和工具服务之间的通信协议。应用在这条协议上有两个方向：

| 方向       | 做什么                                  |
| ---------- | --------------------------------------- |
| **往里接** | 把第三方 MCP 服务接进来，扩展助手的能力 |
| **往外开** | 把盒子助手的工具开放给外部 MCP 客户端   |

设置入口：**设置 → MCP**。页面分上下两部分，上半页是往里接，下半页是往外开。

![设置 → MCP](/shots/settings-mcp.png)

## 往里接：第三方 MCP 服务

上半页分两组：**内置**（盒子自己装好的，如虚幻引擎工具集、Blender）和**手动配置**（你自己添加的）。

### 添加一条服务

点「添加服务」，填：

| 字段             | 说明                                             |
| ---------------- | ------------------------------------------------ |
| **标识**         | 字母、数字、下划线、连字符，最长 32 位，不能重复 |
| **连接方式**     | 本地命令（stdio）或远程服务（HTTP）              |
| **启动命令**     | stdio 方式填这个                                 |
| **服务地址**     | HTTP 方式填这个                                  |
| **环境变量**     | 每行 `KEY=VALUE`，也可以直接粘贴 JSON            |
| **停用**         | 保留配置但不连接                                 |
| **信任此服务器** | 见下方「审批与信任」                             |

填完点「**保存并连接**」。连上之后这一条显示「已连接 · N 个工具」；连不上显示「连接失败」，旁边有「重新连接」。

Claude Desktop 格式的 JSON 可以直接粘贴，不用逐字段转写。

### 审批与信任

助手调用第三方 MCP 的工具时，默认逐次请求你批准。在服务配置里打开「**信任此服务器**」后：

| 审批模式 | 调用这台服务器的工具 |
| -------- | -------------------- |
| 帮我批准 | 不再逐次确认         |
| 请求批准 | 仍然确认             |

### 配置文件

页面上显示配置文件（`mcp.json`）的路径，旁边有「打开位置」和「复制」。

::: danger 删除服务不可撤销
点「删除」并确认后，这一条会立即从 `mcp.json` 中移除，不需要再保存。填好的启动命令和环境变量一起消失。
:::

### 保存不了

有配置填写不完整时，「保存并连接」不可点，页面提示「N 条配置填写不完整，修正后方可保存」。常见原因：标识为空、标识重复、环境变量格式不对。

### Blender

「Blender」一行提供「一键接入」，安装官方 Blender Lab MCP 服务和 Blender 插件，并自动填写配置。需要联网。

- 需要 Blender 5.1 或更高版本、Git、Python 3.11 或更高版本。缺哪个，页面会点名。
- 仅支持 Windows 和 macOS。
- 安装需要几分钟。Blender 装在非标准位置时，点「选择…」指定程序路径。

## 虚幻引擎自带的工具集

连接的工程使用 **UE 5.8 或更高版本**时，应用自动接入引擎官方的 MCP 工具集，在页面上标记为「**自动发现**」。该条目不需要手动配置。

### 开启

引擎侧没开的话，这里有一个「**一键开启**」按钮。它会更新项目文件和编辑器偏好。**完成后需要重启虚幻编辑器**，UE 不能热加载新的插件模块。开启后可以在虚幻的 `Edit > Plugins` 里关掉。

状态显示：

| 显示                     | 含义                  |
| ------------------------ | --------------------- |
| 已配置 · 请重启编辑器    | 配置已写入，需重启 UE |
| 已开启 · 运行中          | 正常工作              |
| 引擎版本过低 · 需要 5.8+ | 这个工程用不了        |

### 看不到这块

显示「尚未连接虚幻引擎项目」时，先在首页打开一个工程，这里才会显示它能不能用。

刚更新过应用且显示检查失败时，重启应用后再查看。

### 「怎么只有三个工具」

「已连接 · N 个入口」里的数字是**入口数**，不是工具数。每个入口内部包含多种引擎操作，助手按任务需要选用。

## 往外开：共享盒子助手的工具

开启「**开放给外部客户端**」后，Claude Code、Cursor 等客户端连上来，拿到的工具和说明与盒子里的助手相同。

**仅本机可连，需要令牌，默认可写。**

### 外部客户端能用什么

| 类别             | 说明                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| 引擎与素材库     | 引擎工具、素材库搜索与导入、工程库管理                                                                 |
| 本机文件与命令   | 读写本机文件、执行命令（可写档位下）                                                                   |
| 浏览器           | 内嵌浏览器                                                                                             |
| 技能             | 用 `load_skill` 加载                                                                                   |
| 第三方 MCP       | 你在上半页接入的服务                                                                                   |
| 笔记与知识库     | 检索覆盖**全盒子**的知识库，可按标题指定一个；存来源按标题存进已有知识库                               |
| 配乐、配音       | 不需要盒子里的对话，也能单独生成配乐（`generate_task_music`）和台词配音（`generate_speech`，输出 WAV） |
| `box_*` 三个工具 | 见下                                                                                                   |
| `task`           | 派子任务，见下                                                                                         |

#### 管理盒子：`box_*`

外部会话用它们看见并管理盒子本身：

| 工具           | 用途                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------- |
| `box_sessions` | 列出、读取盒子助手的对话记录，了解它做过什么、卡在哪                                            |
| `box_status`   | 一次看清运行中的编辑器、素材导入任务（含卡住的）、第三方 MCP 是否连通、技能、知识库、数据库备份 |
| `box_manage`   | 开关技能、重连或删除第三方 MCP、续传或放弃导入、重新导入资产或文件夹、立即备份数据库            |

恢复或删除备份、修改盒子设置、改动盒子自己的对外 MCP 服务不在其内，需要你在盒子界面里操作。`abandon_import` 和 `remove_mcp_server` 不可逆。

#### 派子任务：`task`

`task` 把一件事交给盒子里的子 Agent 做。外部会话的对话不在盒子里，子任务只拿到调用时写的 prompt。

- 默认用盒子里配置的 Agent 模型。配置了多个模型时，`task` 多一个 `model` 参数，调用方可以点名用哪个。
- 客户端批准派发，等于批准了子任务要做的事。`task` 在工具注解里标为破坏性。

#### 进度

调用方在请求里带了 `progressToken`，盒子就在工具运行期间发送 MCP `notifications/progress`。`task` 这类要跑几分钟的工具靠它避免被调用方的超时判死。

### 接上去

页面下方的「**连接配置**」里点「复制配置」，粘贴到外部客户端的 MCP 配置文件里。令牌出于安全只显示头尾，要完整的用「只复制令牌」。

### 权限

「外部客户端的权限」默认是**可写**，页面会写明当前档位：

- 「当前只读。打开后允许外部客户端创建、修改和删除。」
- 「当前可写：外部客户端可修改和删除资产、读写本机文件、执行命令。」

服务运行中可以切换档位：服务自动重启，按新档位开放工具，已连着的会话断开，外部客户端重连即可。配置里已经存成只读的，升级后仍保持只读。

::: danger 保持可写前需要了解这四条

1. 盒子**不对外部客户端弹出审批窗，写操作直接执行**。是否拦截由客户端自己的审批设置决定：工具清单带 MCP 标准注解（只读 / 破坏性），Claude Code、Codex 等按注解决定要不要问你。
2. 可写档位下，外部客户端可以读写本机文件和执行命令。
3. **令牌泄露意味着持有者可以修改你的工程和本机文件。**
4. 怀疑泄露就点「**重置令牌**」。重置后所有已配置这个服务的外部客户端立刻断开，需要重新粘贴配置。

:::

### 端口

默认端口可以改，范围 1024–65535。**服务运行中改不了端口**，需要先关掉上面的开关。

### 工具数量

「运行中 · 开放 N 个引擎工具」统计的是盒子自身的引擎工具总数，与上半页各第三方服务显示的工具数不是同一口径。

### 自动运行

开关状态会保留，下次启动应用时自动运行。

## 和「工具」设置页的关系

第三方 MCP 带入的工具不出现在 设置 → 工具 的清单里，在本页管理。
