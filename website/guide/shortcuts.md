# 快捷键

改键、看冲突、恢复默认。**设置 → 快捷键**。

![设置 → 快捷键](/shots/settings-shortcuts.png)

## 默认绑定

| 动作                                      | 默认键                             | 类型       |
| ----------------------------------------- | ---------------------------------- | ---------- |
| 呼出/隐藏主界面                           | <code>Alt + &#96;</code>（反引号） | 随时可用   |
| [呼出/隐藏快捷提问窗口](/guide/spotlight) | `Ctrl + Shift + Space`             | 随时可用   |
| 进入截图模式                              | `Ctrl + Shift + F12`               | 随时可用   |
| 刷新当前页面                              | `Ctrl + Shift + R`                 | 应用内使用 |
| 语音下指令                                | `Alt + Q`，默认未启用              | 随时可用   |
| 打断语音助手                              | 默认未绑定，也未启用               | 随时可用   |

macOS 上 `Ctrl` 对应 `Cmd`。

「随时可用」是全局热键，应用在后台也生效。「应用内使用」只在应用处于前台时生效。

::: warning 还有一个不在这张表里
**`Ctrl + Shift + M`** 开关[快捷问答小窗](/guide/spotlight#小窗)。它是写死的，这一页改不了它，也看不到它。

上面的「启用快捷键」总开关管得到它：关掉总开关，它也不生效。按了没反应，通常是这个组合被别的软件占用了，而这一项不会出现在冲突汇总里。
:::

## 修改

点对应行的「修改」，按下组合键，Esc 取消。

组合键至少需要包含 `Ctrl`、`Alt`、`Shift` 之一。被其他程序占用时会提示「无法使用此快捷键，可能已被其他程序占用，请换一个」。

已被占用的快捷键在列表中标记为「已被其他程序占用」，页面顶部会汇总为「快捷键冲突」。

## 全局开关

「**启用快捷键**」是总开关。「**恢复默认**」还原所有绑定。

## 语音下指令

默认未启用。因为它会打开麦克风，需要你在列表里自己打开这一项。

启用后，按住热键说话，松手即把听写结果提交给 Agent；短按（不足 0.35 秒）则进入听写状态，说完自动提交。听写用「设置 → 模型 → 默认模型 → 语音识别」，没配置时回退到实时语音通道，见[默认模型](/guide/ai-setup#默认模型)。

## 打断语音助手

该项默认未绑定，需要自行配置。

默认是全双工的，开口说话本身就能打断助手，这个快捷键（或点击界面上的球体）用于不想出声时的静默打断。详见[语音通话](/guide/voice#打断)。

## 对话中的发送键

在 **设置 → AI 助手 → 发送快捷键**：

| 选项          | 回车 | 换行         | 临时切换            |
| ------------- | ---- | ------------ | ------------------- |
| **回车**      | 发送 | Shift + 回车 | Ctrl + 回车         |
| **Ctrl+回车** | 换行 | 回车         | Ctrl + Shift + 回车 |

「临时切换」指当次以另一种方式处理消息（排队或调整方向）。
