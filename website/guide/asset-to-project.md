# 资产库：导入到 UE 工程

把库里的素材导入虚幻工程。

## 基本流程

选中资产或文件夹 → 右键「**导入项目**」→ 选目标工程 → 「开始导入」。

文件夹会连同其中的资产一起导入。弹窗标题标明本次导入的内容：「导入 N 项（文件夹包含其中的资产）」「导入文件夹：某某（N 个资产）」。

## 选择目标工程

弹窗里列出已登记的工程，可按名称或路径搜索，按 UE 版本筛选，也可以点「添加工程」登记新工程。

### 工程要不要开着

| 导入内容                                             | 工程是否需要在 UE 中打开   |
| ---------------------------------------------------- | -------------------------- |
| `.uasset`、`.umap` 等虚幻资产                        | 不需要，直接复制到工程目录 |
| 模型、贴图、音频等外部文件，并选择「转换为虚幻资产」 | 需要，转换由 UE 完成       |
| 规范化导入                                           | 需要                       |

工程没开着时，目标工程旁标「未打开」，按钮变成「**打开工程并导入**」。点它后盒子会启动该工程，等 UE 连上盒子后自动开始导入。

等待超时，或工程已开着但没连上（通常是 UnrealAgentLink 没启用）时，弹窗会给出原因。处理办法见[连接虚幻引擎](/guide/plugin)。

### 外部文件的处理方式

导入内容里有模型、贴图等非虚幻资产时：

| 选项               | 结果                                |
| ------------------ | ----------------------------------- |
| **转换为虚幻资产** | 经 UE 转换，导入到 `/Game/Imported` |
| **保留原格式**     | 原样复制到 `Content/Imported`       |

引擎没连上时，改为二选一：「仅导入虚幻资产」或「全部导入，保留原格式」。

### 导入路径与规范化导入

弹窗里的「导入路径」设置资产在工程中的位置，例如 `Imported`。

「规范化导入」只对 `.uasset`、`.umap` 生效，会把资产规范化导入到该路径下，并需要 UE 已连接。

## 导入前的检查

选好工程后，盒子先做两项检查。

### 引擎版本

结果有三种：

| 显示                                                 | 含义                       |
| ---------------------------------------------------- | -------------------------- |
| 未发现版本冲突                                       | 可以直接导                 |
| N 项需要更高版本的引擎，开始导入时将提示选择处理方式 | 有冲突，开始导入时要做选择 |
| 版本检查失败                                         | 预检本身没有完成           |

另有一条固定提示：外部文件、插件和压缩包能否使用，取决于其内容和目标引擎，无法仅凭文件头判断。

**有资产版本过高时**，弹窗写明目标工程是 UE X，并列出需要更高版本的资产（太多时折成「…，等 N 项」）。三个选择：

- **更换工程**：改选版本足够高的工程
- **仅导入其余项**：跳过这几项
- **仍然导入** / **仍然全部导入**：原样复制文件，不做版本转换，在 UE 中通常无法打开

### 资产要用的插件

导入的资产依赖某些引擎插件，而目标工程没启用时，弹窗提示「需启用 N 个插件」，列出插件名。

| 按钮         | 作用                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| **启用插件** | 把这些插件写入工程的 `.uproject`，重启虚幻编辑器后生效。工程开着时，先让编辑器启用，再写入文件并回读确认 |
| **暂不启用** | 不改工程。未启用时，蓝图编译会报「无效类型」「找不到函数」等错误                                         |

盒子只能启用本机已有的插件。本机没有的插件，以及原工程自己的 C++ 代码，会单独列在「本机缺少 N 项」下：

- 已知来源的插件，提供「在 Fab 上查看」
- 只知道模块名的，标注可能来自第三方插件或原工程的 C++ 代码
- 这些项在安装之前，相关蓝图打不开。原工程的 C++ 代码需要连同源码一起复制并编译

通过助手导入时，导入结果会写明下一步，助手也可以启用本机已有的插件。

### 资产指南（缺失的项目设置）

部分资产自带「资产指南」，要求目标工程具备特定的项目设置。由助手执行：

- **查**：只读，对照这些资产的要求，列出工程里缺哪些设置
- **改**：把要求的设置写入工程的 `Default*.ini`，并从磁盘读回确认。执行前需要你同意

助手把库里的 `.uasset` 导入工程后，会自动检查这批资产的指南，没满足的项连同判断依据写进导入结果。

## 压缩包

导入压缩包时，会询问处理方式：

| 选择           | 结果                                         |
| -------------- | -------------------------------------------- |
| **解压后导入** | 内容解到工程的 `Content` 里，UE 里直接能看到 |
| **原样复制**   | 压缩包放入 `Content/Imported`，需自行解压    |

可以勾「以后均按此方式处理」。也可以在 **设置 → 资产库 → 压缩包导入前询问** 里关闭这个询问，关闭后一律解压后导入。

解压完成后，提示解压的文件数量和目标目录。包内如果是 FBX、贴图等源文件，需要在 UE 中再次导入。

::: warning 只能解 ZIP
其他格式会提示「虚幻盒子仅支持解压 ZIP。{格式}格式请先使用解压软件解压，再将文件夹导入资产库。」
:::

## 导入插件

资产右键有「**导入插件到项目**」，把库里的插件包导入目标工程。成功后提示「插件 {名称} 已导入到 {路径}」。

## 导入进度与中断

进度挂件属于应用整体，切换到其他页面后仍然可见，也可以从挂件中止导入。

挂件显示：已处理 N/M、成功 N、已存在 N、失败 N。

### 上次没导完

再次进入时，如果提示「检测到上次导入未完成，可以继续导入」，可选择**继续导入**或**忽略**。

## 助手也能做这件事

也可以在 AI 对话中要求导入，例如「把素材库里那几个树的模型导到 XX 工程」。助手走同一套流程，出现版本冲突时同样会询问你。

需要工程已连接，见[连接虚幻引擎](/guide/plugin)。

**设置 → AI 助手 → 修改资产时设为只读**（默认关闭）：开启后，助手修改资产期间，对应的 `.uasset` 文件会被设为只读，防止编辑器里的保存覆盖助手的改动。这期间这些资产在编辑器中暂时无法保存。
