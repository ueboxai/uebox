# 安装与更新

下载、装上、保持更新。不需要账号，也不用填任何信息。

## 下载

官网上是直接下载：<https://uebox.ai/#download>。历史版本和校验和在
[GitHub Releases](https://github.com/ueboxai/uebox/releases)。

| 系统    | 获取方式                                                      |
| ------- | ------------------------------------------------------------- |
| Windows | Releases 里的 `.exe` 安装包。这是主要支持平台                 |
| macOS   | 暂不发布安装包，从源码构建，见[从源码构建](#从源码构建)       |
| Linux   | 暂不发布安装包，从源码构建。构建出的包不含 `uebox` 命令行工具 |

装完第一次打开，先选一次界面语言，然后进入项目库。项目库会列出本机装了哪些虚幻引擎，但**不会扫硬盘找工程**，工程需要你自己导入。完整的启动顺序见[第一次打开](/guide/first-run)。

## 更新

有两个入口，走的是同一条流程：

- **设置 → 关于 → 检查更新**
- 侧边栏左下角版本号旁的更新角标

每一步都会先问你，不会自动下载，也不会在退出时自动安装：

| 步骤     | 界面                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 发现     | 「发现新版本 {版本}，是否立即下载？」，可以选「稍后」                            |
| 下载中   | 角标显示「下载中 N%」；设置里提示「正在下载更新，完成后将提示安装」              |
| 下载完成 | 角标变成「重启更新」，点击后弹出「新版本 {版本} 已下载完成，是否立即重启安装？」 |

角标有三种状态：「新版本」（点击开始下载）、「下载中 N%」、「重启更新」（已经下好，随时可以装）。

::: tip 为什么不自动下载
安装包几百 MB，下载会占用带宽和磁盘，所以发现新版本后先问你，安装也由你决定。
:::

应用启动后会静默检查一次，之后每 4 小时再查一次。这两次不弹窗，有新版本时只显示角标。

退出或安装更新时，如果 AI 还有操作没做完，会先提示「AI 仍有 N 项操作正在进行」，可以选「仍然退出」或「仍然重启安装」，也可以取消。

取不到更新时有两种提示：「暂时无法获取更新，请稍后重试。」表示取不到更新清单，「暂时无法连接更新服务器，请检查网络后重试」表示连不上。

### 更新源

只有一条线：上述 GitHub 仓库的 Releases。由 `package.json` 的 `updateGithubRepo` 字段指定，也可以用 `updateFeedUrl` 指向自架的静态源。

::: warning 没配置更新源 = 一次网络请求都不发
这是社区版的硬规则。改过那个字段（例如打包自己的 fork）而没有填新的源时，构建出的版本**不带更新源**，不会加载 electron-updater。

所以第三方自己编译的版本不会收到官方安装包的更新。
:::

## 从源码构建

需要 [Node.js 24.21.0](https://nodejs.org/) 和 pnpm 10.28.2。macOS、Linux 目前走这条路。

```bash
pnpm install
pnpm dev
```

首次 `pnpm install` 需要编译原生模块，耗时几分钟。打包与插件构建见[给开发者](/develop/)。

## 卸载

按系统常规方式卸载。卸载**不会**删除你的应用数据 —— 资产库索引、笔记、设置都在独立目录，见[文件都放在哪](/guide/where-is-my-data)。要彻底清干净，卸载后自己去那个目录删。
