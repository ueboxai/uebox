# 项目库

登记工程后，Agent 才能操作它。只有已登记并连上盒子的工程可以被 Agent 操作。

项目库是侧边栏第一项，也是应用的默认页面。上半部分是**引擎版本**，下半部分是**我的项目**。

![项目库](/shots/home-projects.png)

## 引擎版本

启动时，盒子会扫描本机已安装的虚幻引擎。每个版本卡片上可以：

- **启动**：不带工程打开编辑器
- **设为默认 / 取消默认**：部分操作需要一个默认引擎
- **安装目录 / 插件目录**：打开对应文件夹
- **移除引擎**：只从列表移除，**不删除硬盘上的引擎文件**

点右上角「刷新」重新扫描。发现失效的引擎记录时，会询问是否从列表清理，这一步同样只改列表。

::: tip 没扫到引擎
列表显示「未找到已安装的虚幻引擎」时，把引擎根目录（含 `Engine/Binaries/Win64/UnrealEditor.exe` 的那一层）**拖到引擎区域**，或点 `+` 手动添加。

Epic Games Launcher 安装的引擎，请在 Launcher 里管理。
:::

读取失败和确实没装，界面提示不同：

| 提示                       | 含义                                           |
| -------------------------- | ---------------------------------------------- |
| 扫描引擎失败，列表可能不全 | 点刷新时扫描出错                               |
| 读取引擎列表失败           | 本次读取失败，不代表没装引擎。点右上角刷新重试 |
| 未找到已安装的虚幻引擎     | 扫描正常完成，但没有结果                       |

## 导入工程

盒子不会扫描硬盘找工程，需要你指给它。导入只把路径登记到列表，**不移动、复制或修改工程文件**。

| 方式         | 操作                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| 拖入         | 把 `.uproject` 文件或工程目录拖到项目库页面                                            |
| 从引擎记录选 | 点「导入已有工程」，在列表里点工程；列表来自本机引擎最近打开过的工程，也可「全部导入」 |
| 手动选文件   | 在「导入已有工程」窗口底部点「选择 .uproject 文件」                                    |

拖入的目录里有多个工程时，会让你勾选要导入的工程。

批量导入后，提示按段拼成，例如「成功导入 3 个，2 个已存在，1 个失败」。把上周导过的目录再拖一次，结果就是「已存在」。

### 导入到分组

先点中某个分组按钮，再导入，工程会直接进入该分组。

「导入已有工程」列表里，已经在库里的工程标「已导入」。选中了分组时，这些工程可以点击加入分组（悬停显示「加入分组」），不会重复登记。

## 新建工程

点「创建项目」→「**用模板新建工程**」。

流程：选模板 → 填工程名称 → 选保存位置 → 「创建工程」。

### 模板市场

模板有两类来源：**我的**（本地模板库）和**社区**（线上模板源）。

::: warning 默认不联网
模板来自线上模板源。默认不启用模板源，此时盒子**不发起任何网络请求**。启用后才会获取模板列表。

官方源有 **GitHub** 和**国内镜像**两个地址，启用时会一起启用，盒子自动使用能连通的那个。
:::

- **筛选**：来源（社区 / 我的）、用途（游戏 / 渲染 / 影视 / 建筑 / 汽车 / 其他）、引擎。有搜索框，顶部显示「N / M 个模板」，「清除筛选」恢复全部
- **排序**：推荐排序、按名称、按大小、最近添加
- **下载**：社区模板需先下载到本地模板库，才能用来建工程

::: danger 社区模板未经审核
界面提示：「社区模板由第三方提供，未经官方审核。安装前请确认来源可信。」
:::

部分源连不上时，界面提示「{N} 个源连接失败，模板列表来自其他源」，或具体到「源「{名称}」获取失败：{原因}」。源里有不合规条目时，提示条目数量，这些条目会被忽略。

### 管理模板源

「管理模板源」里能看到内置源，也能添加或删除自己的源。添加时填名称和清单地址。

### 添加自定义模板

点「添加自定义模板」，填模板名称，选一个源工程路径。该工程会被存成一个「我的」模板。

## 工程卡片

右键菜单：

| 菜单项                      | 说明                                                               |
| --------------------------- | ------------------------------------------------------------------ |
| 打开项目                    | 用对应版本的引擎启动                                               |
| 打开 C++ 工程               | 打开 `.sln`；没有时提示「未找到 sln 文件」                         |
| 打开目录                    | 打开工程文件夹                                                     |
| 自定义封面 / 恢复自动封面   | 换成自选图片，或恢复自动生成的封面                                 |
| 重命名                      | **只改应用里显示的名字**，不改磁盘上的文件                         |
| 置顶项目 / 取消置顶         | 固定在列表最前，卡片上标「已置顶」                                 |
| 安装桥接插件 / 移除桥接插件 | 安装或移除 UnrealAgentLink，见[连接虚幻引擎](/guide/plugin)        |
| 移出分组                    | 从分组里拿掉，工程仍在总列表。工程属于多个分组时，菜单项写明分组名 |
| 移除项目                    | 从列表移除，**不删除工程文件**                                     |

### 同名工程在不同路径

盒子按路径区分工程。两个工程同名但路径不同时，侧边栏的对话按路径分组显示。新建对话和选择工程时也带上路径。

## 分组

在空白处右键，选「创建分组」。分组显示为列表上方的一排筛选按钮：

| 按钮       | 显示内容               |
| ---------- | ---------------------- |
| **全部**   | 所有工程               |
| **未分组** | 没有归入任何分组的工程 |
| 分组名     | 该分组里的工程         |

把工程卡片**拖到分组按钮上**即可加入分组。要拿出来，用右键的「移出分组」。

解散分组时，分组本身被移除，其中的工程回到「未分组」，不会删除任何工程。

## 搜索与筛选

可以按工程名搜索，也可以按引擎版本筛选（包含「版本未知」）。列表为空时，提示分三种：

| 提示                         | 含义                                       |
| ---------------------------- | ------------------------------------------ |
| 未找到匹配「{关键词}」的工程 | 搜索无结果，清空搜索框即可                 |
| 暂无「{版本}」的工程         | 版本筛选无结果，换一个版本或选「全部版本」 |
| 读取工程列表失败             | 本次读取失败，不代表没有工程。刷新页面重试 |

## 工程找不到时

打开一个已被删除或移走的工程时，弹窗标题是「找不到该工程」，正文给出登记的路径，并询问是否从列表移除这条记录。

点「刷新」时，如果发现一批这样的记录，会询问「是否将这些失效项目从列表中移除？」。该操作不会删除磁盘上的项目文件。没有失效记录时，提示「未发现失效项目记录」。

## 打开工程之后

**设置 → 项目库 → 打开工程后隐藏主界面**：开启后，从应用内启动工程时主界面收入托盘，后台任务继续运行。默认关闭。

## 插件没装上

导入工程时如果 UnrealAgentLink 没装成功，会弹窗，标题是「**工程已导入，但 AI 无法连接该引擎**」，正文写明原因。三种原因及处理办法见[连接虚幻引擎](/guide/plugin#导入工程时提示插件没装上)。

弹窗上的「**交给 AI 排查**」会新开一条对话，把工程路径和盒子报的原因码交给助手，并列出该查的几处：`.uproject` 能否读取、`EngineAssociation` 写的版本、插件目录是否存在、本机有没有对应版本的引擎。

也可以事后在工程卡片右键里选「安装桥接插件」。
