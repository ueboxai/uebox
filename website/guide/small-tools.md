# 录屏与截图

给库里的条目录制动图封面，或截取一块屏幕区域。

## 录屏是给封面用的

应用里的录屏用来给库里的条目录制封面，**侧边栏没有它的入口**。它从两个地方触发：

- **蓝图库 / 材质库** —— 卡片右键 →「⏺ 录制封面」
- **资产库** —— 资产详情面板里录制预览图

点击后弹出独立的**快速录制窗**，录完的片段回填为那张卡片的封面。资产详情里录制完成后，会询问是否删除原始录制文件，删除后无法恢复。

## 快速录制窗

| 选项       | 说明                                           |
| ---------- | ---------------------------------------------- |
| **模式**   | 全屏 / 选区                                    |
| **帧率**   | 30 帧 / 60 帧                                  |
| **屏幕源** | 列出可用的屏幕和窗口，认不出来点「刷新屏幕源」 |

选「选区」会先显示选择遮罩（「拖拽鼠标选择录制区域」）：拖拽框出区域，点「确认」；按 **ESC** 退出。

全屏模式下录制窗会自动收起。

录制中可以暂停，也可以重新录。

提示「未检测到屏幕源」时先点「刷新屏幕源」。仍然没有时，通常是系统没有授予屏幕录制权限。

## 录制库

**设置 → 录屏**。这一页列出所有录制文件，没有设置项：

![设置 → 录屏：录制文件库](/shots/settings-screenrecorder.png)

- 左侧是录制列表，可以按文件名搜索、刷新、打开所在目录
- 选中一条看详情：预览、创建时间、文件路径、用系统播放器打开、在文件夹中显示、删除

删除录制不可恢复。

### 剪辑与导出

在录制库里选中一条，进入「录制编辑」：

**剪辑区间** —— 设起点、终点，下面显示剪辑时长。

**导出格式与参数**：

| 项         | 说明                                  |
| ---------- | ------------------------------------- |
| 格式       | MP4 / GIF。**GIF 体积更小但不含音频** |
| 质量       | 高 / 均衡 / 快速                      |
| 帧率       |                                       |
| 分辨率     | 可选「原始」                          |
| 码率       |                                       |
| 包含音频   | **仅 MP4 可用**                       |
| 高质量缩放 | 保持清晰度与细节                      |

导出前有一块「导出摘要」列出格式、时长、帧率、分辨率、质量，确认无误再点「导出」。

## 截图模式

在 **设置 → 快捷键 →「进入截图模式」** 绑定按键，默认 `Ctrl + Shift + F12`。

进入后框选区域，点「截图」。按 **ESC** 退出。透明边缘会保留在截图中。

完成后提示「截图已保存到: <路径>」，失败提示「截图失败」。

## 通知

**设置 → 常规 → 通知**：

| 项             | 默认           | 说明                       |
| -------------- | -------------- | -------------------------- |
| 任务完成提醒   | **仅在后台时** | 任务完成时通知，带结果摘要 |
| 需要确认时提醒 | **开**         | 后台运行时通知待确认的操作 |
| 需要回答时提醒 | **开**         | 后台运行时通知待回答的问题 |

审批等待 5 分钟无人响应，按拒绝处理。关闭「需要确认时提醒」后，后台出现的审批不会通知你。
