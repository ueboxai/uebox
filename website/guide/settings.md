# 设置速查

设置页左侧菜单分三组。这一页按菜单的**实际顺序**列出每一项管什么，细节链到对应章节。

::: tip 两项默认不显示

- **MiniChat** 的设置面板在当前版本是关掉的，菜单里没有这一项。小窗的透明度和是否保存历史都是固定值，改不了。
- **Agent V3 调试台** 只在开发环境出现，正式安装包里看不到。

菜单里没有它们是正常的。
:::

## 第一组：基础

### 常规

- **启动行为 → 开机自启** —— 默认关闭。关掉之后，盒子不会再自行改回开启
- **通知** —— 任务完成提醒（关闭 / 仅在后台时 / 始终）、需要确认时提醒、需要回答时提醒

见[通知](/guide/small-tools#通知)。

### 外观

- **语言** —— 中文（简体）/ English。切换后部分内容需要刷新页面生效。
- **主题** —— 跟随系统 / 浅色 / 深色 / 自定义
- **自定义主题颜色** —— 主色、辅色、强调色。会校验对比度，过低时提示，但仍可应用。
- **减少动态效果** —— 跟随系统 / 开启动效 / 减少动效

### 快捷键

全局热键与应用内快捷键，带冲突检测。见[快捷键](/guide/shortcuts)。

![设置 → 快捷键](/shots/settings-shortcuts.png)

## 第二组：AI

### AI 助手

分四段，括号里是默认值：

| 段           | 设置项                     | 作用                                                                                              |
| ------------ | -------------------------- | ------------------------------------------------------------------------------------------------- |
| **对话**     | 追问建议                   | 回复后生成相关追问                                                                                |
|              | 自动生成新标题             | 每轮回复结束后，按整段对话重起标题                                                                |
|              | 归档对话                   | 查看、恢复、删除已归档对话                                                                        |
| **输入**     | 发送快捷键                 | 回车发送（Shift+回车换行），或 Ctrl+回车发送（回车换行）                                          |
|              | 运行中发送的消息           | 「完成后处理」或「调整方向」                                                                      |
| **任务执行** | 浏览器显示方式             | 独立窗口 / 嵌入助手 / 隐藏，见[权限](/guide/tools-and-skills#权限)                                |
|              | 修改资产时设为只读（关）   | 开启后，Agent 修改资产期间把对应的 `.uasset` 设为只读，编辑器里的保存会暂时失败，避免覆盖它的改动 |
|              | 自动断点续传（开）         | 模型服务不稳定时每 60 秒从断点继续，连续失败 30 分钟后停止。失败的重试不保留在对话中              |
|              | 目标模式最大轮数（10）     | `/goal` 复核未通过时最多再改几轮，范围 1–50，下一条消息起生效                                     |
| **隐私**     | 文件访问范围               | 仅虚幻相关（默认收窄）/ 整台电脑，见[权限](/guide/tools-and-skills#权限)                          |
|              | 允许编辑器截图             | 允许 Agent 获取虚幻编辑器画面                                                                     |
|              | 允许浏览器访问局域网（关） | 允许 Agent 浏览器打开 `localhost`、`192.168.x.x` 这类本机和局域网地址，用于查看本地开发服务器     |
|              | 已设为始终允许的操作       | 在审批卡片上点过「以后均允许」的操作都列在这里，可逐项「移除」。只读对话不受影响                  |

### 模型

服务商、API 密钥、模型清单、各用途的默认模型，页面顶部有 Box Plan 卡片。见[配置模型](/guide/ai-setup)。

![设置 → 模型](/shots/settings-models.png)

### 团队

`/team` 团队模式用过之后才有内容：列出检测过或参与过任务的模型，每个模型一行，包含入职检测结论（连通、工具调用、识图）、任务数、被你重开的任务数（打回）、未完成数、最近使用时间、岗位和平均耗时。点「重新检测」可以重测某个模型。

### 技能

27 个内置技能与自定义技能，可逐个开关、查看和编辑。「自动记录做法」分三档：关闭 / 先确认 / 自动。见[工具、技能与权限](/guide/tools-and-skills#技能)。

![设置 → 技能](/shots/settings-skills.png)

### 经验库

执行任务时遇到并已解决的问题。再次出现相同报错时，盒子自动提示这条经验；无效的经验自动淘汰。可以按「通用」「工程」筛选，显示已淘汰的条目，删除单条，或撤销上一次整理。「技能」页的自动记录关闭后，已有经验保留，但不再提示。

### 工具

按类别折叠的工具清单，可逐个或整类开关，顶部有「工具搜索（Beta）」的两档选择，默认开启（按需提供工具）。见[工具](/guide/tools-and-skills#工具)。

![设置 → 工具](/shots/settings-tools.png)

### 个性化

给助手的常驻说明，所有对话都会带上。见[给助手交代背景](/guide/tools-and-skills#给助手交代背景)。

### 语音

麦克风、自动播放、助手反馈详细程度、无人回应自动挂断。见[语音通话](/guide/voice)。

### MCP

接入第三方 MCP 服务，或把引擎能力开放给外部客户端。见 [MCP](/guide/mcp)。

![设置 → MCP](/shots/settings-mcp.png)

### 命令行

`uebox` 的程序位置和「加入 PATH」。见[命令行](/guide/cli)。

### 用量

从已有对话记录统计，不是服务商账单。可按今日 / 7 天 / 30 天 / 全部查看。

| 指标         | 口径                           |
| ------------ | ------------------------------ |
| 对话轮次     | 一次提问算一轮                 |
| 工具调用     | 调用次数合计                   |
| 不含缓存共计 | 按全价计费的那部分             |
| 平均每轮     | 不含缓存命中的 token           |
| 缓存命中率   | 命中部分的单价通常低一个数量级 |
| 输出         | 含模型的思考过程               |
| 改动         | 成功修改工程的操作数           |

## 第三组：工程与资产

### 项目库

- **打开行为 → 打开工程后隐藏主界面** —— 默认关闭。开启后打开工程时主界面收到托盘，后台任务继续运行，见[系统托盘](/guide/interface#系统托盘)。

### 资产库

- **删除确认** —— 删除文件或文件夹前询问。开启后会恢复之前关闭的确认提示。
- **显示依赖资产** —— 关闭后只显示手动导入的资产
- **压缩包导入前询问** —— 关闭后一律解压后导入
- **跨库搜索** —— 默认关闭。关闭时 Agent 找素材只搜当前保管库；开启后同时搜其他保管库
- **默认应用** —— 图片 / 视频 / 3D 模型 / 音频 / 代码 / UE 资产各自的打开方式，可以逐类指定程序，也可以恢复默认
- **语义搜索** —— 按语义匹配资产名称，使用「模型」中配置的嵌入模型建立索引，费用由服务商决定。开启时显示建索引进度，中断后可以「继续」。关闭会删除已有索引，重新开启需要重建；关键词搜索不受影响。
- **高级 → 启用局域网协作库** —— **默认开启**。关掉之后，新建资产库时就不显示「网络协作库」这个选项

详见[资产库](/guide/asset-library)。

### 知识库

- **网页导入 → 读取网页里的图片** —— 识别网页图片中的文字并标注为「AI 识别」。**默认关闭**，会产生模型费用。开启后可限制每篇识别的图片数量。
- **笔记自动索引** —— 编辑笔记后自动更新索引
- **数据管理 → 重建知识库索引**

### 对象存储

接入你自己的 S3 兼容存储桶：连接配置、测试连接、已上传文件的数量与清理、自动清理天数。哪些功能会用到、各家怎么配，见[对象存储](/guide/object-storage)。

### 插件

UnrealAgentLink 的连接状态、已连接的工程数、自动安装开关、崩溃恢复开关（允许 Agent 重开崩溃的编辑器，默认开）、清理旧版插件、插件源码链接。见[连接虚幻引擎](/guide/plugin)。

![设置 → 插件](/shots/settings-plugin.png)

### 录屏

这一项不是设置，是**录制文件库**：列表、搜索、预览、剪辑与导出。见[录屏与截图](/guide/small-tools#录制库)。

### 命名规则

四张表，既用于「从电脑导入时落到哪个目录」，也用于「AI 整理工程时判断归属对不对」：

- **资产前缀** —— 各类资产的命名前缀，带示例
- **纹理类型识别规则** —— 用正则从文件名识别 Albedo、Normal 等类型，可逐条启用，带测试框
- **资产归属目录** —— 各类资产的目标目录，例如 `/Game/Imported/Meshes`
- **扩展名映射** —— 文件扩展名对应哪种资产类型

改动会自动保存，也可以手动「保存」「重新加载」。「重置」恢复默认规则，**不可撤销**。

![设置 → 命名规则](/shots/settings-namingrules.png)
