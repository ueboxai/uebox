# 百度网盘与 WebDAV

资产库左侧「网络」区有两个云盘入口：**百度网盘**和 **WebDAV**，用于在云盘与本地资产库之间传输文件。

云盘与[网络协作库](/guide/asset-team)的区别：网络协作库由多人共用同一个库；云盘只是可以浏览、传输文件的存储位置。

## 百度网盘

### 社区版要自己申请应用

**社区版不内置官方应用凭据。** 需要在百度网盘开放平台创建自己的应用，并填入 AppKey 和 SecretKey。

凭据只保存在本机。

### 授权步骤

**准备** —— 点「前往百度开放平台创建应用」，获取 AppKey（`client_id`）和 SecretKey（`client_secret`），填入后点「保存应用凭据」。

**第一步：获取授权码** —— 点按钮前往百度网盘官方授权页，登录后复制页面显示的授权码。

**第二步：验证授权** —— 把授权码粘进输入框，点「提交验证」。

::: warning 授权码有效期 10 分钟
获取后请尽快粘贴；过期后从第一步重新开始。
:::

授权成功后，令牌保存在本机，页面顶部显示账号信息。要断开授权，退出登录即可。

### 浏览与操作

- 面包屑从「根目录」开始
- 搜索框在网盘内搜
- 排序：名称 / 时间 / 大小，各带升降序

**上传**：可以「上传文件」或「上传文件夹」，走系统文件选择器。

**下载到资产库**：把网盘里的文件拖到资产库，或用右键菜单。成功后提示「已保存到资产库：{路径}」。

### 从资产库传上去

资产右键 →「**上传到百度网盘**」。

没授权时会提示「请先授权百度网盘」。

::: warning 不支持文件夹上传
右键菜单这条路径只能上传单个文件，选中文件夹时提示「暂不支持文件夹上传，请选择单个文件」。上传多个文件可以分次操作，或使用网盘页面工具栏的「上传文件夹」。
:::

## WebDAV

### 连接

填三样：**服务器地址**、**用户名**、**密码**，点「连接」。

连过的服务器会记在「历史记录」里，可以一键重连，也可以清空。

连不上的两种提示：

- 「连接失败，请检查服务器地址和凭据」
- 「连接失败，请检查网络和服务器配置」

### 浏览与操作

目录按文件夹和文件分区显示，各自带数量。

**右键菜单**：下载、重命名、删除。

**上传**：点击或拖拽文件到上传区，支持单个或批量。上传过程有进度条，逐个显示完成 / 失败 / 上传中。也可以从工具栏「上传文件」「上传文件夹」走系统选择器。

**下载**：把文件拖到资产库，覆盖层会提示「释放以下载 {名称}」。

### 从资产库传上去

资产右键 →「**上传到 WebDAV**」。没连接时提示「请先连接 WebDAV 服务器」。

### WebDAV 路径

网络协作库的资产，详情面板里会显示一条 **WebDAV 路径**，点击可以跳转过去。
