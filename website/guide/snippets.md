# 蓝图库与材质库

两个库的结构和用途相同，都用来**存放可以反复使用的片段**：蓝图库存蓝图节点图，材质库存材质节点资产。

Agent 处理同类任务时会检索这两个库并参考其中的内容，所以名称、描述和标签写得准确，检索效果更好。Agent 也能往库里存片段、把库里的片段放进工程，见[助手能做什么 · 蓝图库与材质库](/guide/capabilities#蓝图库与材质库)。

两个库都是纯本地的，存放在当前活跃的保管库下面。

![蓝图库画廊视图](/shots/blueprint-library.png)

## 一个条目是一个文件夹

磁盘上，每个条目是保管库里的一个**目录**，目录名自带扩展名：

| 库         | 目录               | 里面有什么                                         |
| ---------- | ------------------ | -------------------------------------------------- |
| **蓝图库** | `名字.ueblueprint` | `blueprint.json`（必需）、`cover.png`、`README.md` |
| **材质库** | `名字.uematerial`  | `material.json`（必需）、`cover.png`、`textures/`  |

这样整个目录可以直接拷走、备份，换一台机器仍然可用。清单是两格缩进的 JSON，可以用记事本打开和手改，也可以纳入 Git 做 diff。

删除库的数据库后重新扫描目录，库的内容会恢复。手动拷进保管库的包也靠扫描识别。

::: warning 不要往包目录里放其他文件
包目录里的 `cover.png` 和 `textures/` 属于这个包，不会被当成独立资产索引。
:::

::: warning 两种读不出来的情况

- **清单里的格式标记对不上**：扩展名对但内容是别的东西，拒绝读取。
- **清单版本比本机新**：读取后再存回会丢掉不认识的字段，所以不读取。升级应用即可。

:::

目录名是显示名洗过的结果（去掉 Windows 非法字符、截到 80 字符以内、避开保留设备名），**两者可能不一致，以清单里的名字为准**。重名按 Windows 的习惯加序号：`跳跃逻辑 (2).ueblueprint`。

## 往里存

### 新建

点「新建蓝图」/「新建材质」，填名称。展开「高级设置」还能填：

- **蓝图库** —— 蓝图类型、引擎版本、描述
- **材质库** —— 材质类型、描述、备注描述

### 拖进来

把蓝图包 / 材质包文件拖到左侧的文件夹里。手动拷进保管库目录的包，下次开库扫描时也会被认出来。

### 从旧版导入

「从旧版导入」用于迁移旧版本的数据。迁移完成后会写入一个一次性标记，防止重复迁移；**旧数据不会被删除**，迁移出问题时仍可找回。同一个旧库只会导入一次，已在库中的条目会跳过。

## 找出来

顶部一排是通用的：

| 控件     | 说明                                           |
| -------- | ---------------------------------------------- |
| **搜索** | 蓝图库搜名称/类型/标签，材质库搜名称/路径/标签 |
| **筛选** | 「★ 只看收藏」                                 |
| **排序** | 最近使用（材质库是最近更新）/ 名称 / 创建时间  |
| **视图** | 网格 / 列表                                    |

**材质库还有这些筛选**：类型（材质 / 材质实例 / 材质函数）、混合模式、着色模型，以及「有依赖贴图」开关。卡片上标出编译状态（正常 / 警告 / 错误 / 未知）。

![材质库画廊视图](/shots/material-library.png)

### 列表视图的列

两个库的列表视图使用通用表头：

- **蓝图库** —— 名称、蓝图类型、引擎版本、统计、标签
- **材质库** —— 名称、材质类型、混合与着色、统计、路径

### 统计列写了什么

- **蓝图** —— N 函数、N 变量、N 图表、N 组件。什么都没有的显示「空蓝图」
- **材质** —— 参数 N · 依赖 N

看这一列可以快速判断片段里有没有内容。

## 文件夹

左侧是文件夹栏，可以新建、重命名、删除，拖动边缘调宽度。

::: tip 删除文件夹不会删除内容
删除文件夹时，其中的条目移回「全部」，不会被删除。
:::

## 集合

多个蓝图（或材质）可以打成一个**集合**，作为一张卡片管理，卡片上标着里面有几个。

集合不属于任何单个条目，存放在保管库根目录的一份单独文件里，两个库共用这一份。拷走整个保管库文件夹时，集合随之带走。

排序方式、视图模式、筛选条件这类界面偏好不在这个文件里，只保存在本机。

## 卡片操作

右键或列表行上的按钮：

| 操作                  | 说明                                               |
| --------------------- | -------------------------------------------------- |
| **修改封面**          | 选一张图片或一段视频                               |
| **录制封面**          | 打开快速录制窗录一段，见[录屏](/guide/small-tools) |
| **恢复默认封面**      |                                                    |
| **编辑信息**          | 名称、描述（材质库还有备注描述）                   |
| **收藏 / 取消收藏**   |                                                    |
| **删除 / 移出材质库** |                                                    |

::: warning 删除暂时不能撤销
蓝图库的确认弹窗写明：蓝图将从蓝图库中移除，此操作目前无法撤销。材质库的「移出材质库」只删除盒子本地库里的记录，不会删除外部工程文件。
:::

## 「有 N 项没能存进保管库」

出现这条提示时，**后续编辑同样无法保存**，需要先处理。

两个常见原因：

1. 切换了保管库
2. 包目录在资源管理器里被改名或移走了

处理完点「重试保存」。

## 空库的时候

蓝图库显示「蓝图库为空」，并提示新建蓝图节点，或从旧版导入已有蓝图。

材质库在没有匹配项时显示「未找到匹配材质资产」，提示调整筛选条件或新建离线材质节点条目。

## 开库要走一遍磁盘

打开库时会递归遍历保管库，并逐个读取清单，条目多的库打开会有延迟。在本地固态盘上，五百个条目约需三百毫秒；读取是异步的，不阻塞界面。

::: warning 网络协作库上没有测过
网络库上每次读目录、读文件都是一次网络往返，耗时可能高一到两个数量级。目前建议两个库都放在本地保管库里。
:::

## 云同步

蓝图库的云同步已经整体下线，社区版和商业版都没有。目前两个库都是纯本地的。
