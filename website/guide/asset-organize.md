# 资产库：检索与整理

素材进库后，可以在这里浏览、搜索、打标签和整理。

入门和建库见[入门与保管库](/guide/asset-library)。

## 浏览

左侧是资产目录树，中间是文件列表，右侧是详情面板（可用工具栏的「详情」收起）。

页面底部有一条状态栏，仅在资产库页面显示。

![进到某个文件夹后的素材网格](/shots/asset-library-grid.png)

### 排序

八种：

| 维度     | 选项            |
| -------- | --------------- |
| 名称     | A-Z / Z-A       |
| 修改时间 | 最早 / 最新     |
| 文件大小 | 小到大 / 大到小 |
| 类型     | A-Z / Z-A       |

在「最近删除」中，排序维度改为**删除时间**（最早 / 最新）。

### 筛选

| 面       | 选项                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------- |
| 格式     | 图片 / 视频 / 3D 模型 / 音频 / 代码 / UE 资产                                                      |
| 资产类型 | 静态网格体、骨骼网格体、蓝图、主材质、材质实例、纹理2D、动画、音效、关卡、数据表、曲线、字体、其他 |
| 大小     | 小于 1MB / 1–10MB / 10–100MB / 大于 100MB                                                          |
| 收藏状态 | 全部 / 已收藏 / 未收藏                                                                             |
| 标签     | 多选                                                                                               |

资产类型支持多选，选定后显示「已选 N 种类型」。右上角「重置」清空所有筛选条件。

### 搜索

搜索范围是**当前文件夹**。未选择文件夹时提示「请先在左侧选择文件夹」。

要搜索整个库，先在左侧选择「全部」。

### 语义搜索

**设置 → 资产库 → 搜索 → 语义搜索**。开启后按语义匹配资产名称，而非仅匹配字面。

索引使用 设置 → 模型 中配置的**嵌入模型**建立，费用由服务商决定。开启后显示建索引进度（已索引 / 总数）；中断后可点「继续」。

::: warning 关闭会删除已有索引
重新开启需要重建索引。关键词搜索不受影响。
:::

## 标签

### 标签库

通过工具栏的「标签管理」打开标签库，或在资产上右键「添加标签」。

标签有两种来源：

- **自动识别的资产类型** —— 由应用解析文件后添加
- **自定义管理标签** —— 用户创建的

侧边分类：全部标签、未分组、常用、最近使用、资产类型、项目状态。

搜索框支持在检索的同时创建：输入不存在的名称后按 `Enter` 直接创建。

### 打标签

选中资产 → 右键「添加标签」→ 在标签库中选择 → 「确认标签」。

详情面板的标签输入框中输入并回车也可添加。

## 颜色标记

文件夹和资产可右键「修改颜色」，从预设中选择或自定义，也可「清除颜色」。

## 收藏与最近删除

- **我的收藏** —— 右键「添加到收藏」，在快捷区单独查看
- **最近删除** —— 删除的内容进入此处，可「恢复」或「彻底删除」，也可整体「清空」

## 详情面板

选中一份资产后右侧显示：

![选中一份资产后的详情面板](/shots/asset-library-details.png)

### 资产信息

资产类型、中文类名、类名、资产分类、引擎版本、格式、创建与修改时间。

**软路径**点击复制，用于在 UE 内容浏览器中定位该资产。

**本地路径**点击复制实际文件路径。网络库另外显示 WebDAV 路径。

### 预览图

可更换（拖入图片或视频，或点「选择预览图」）、裁剪、重置为默认，也可录制一段动图作为预览，见[录屏](/guide/small-tools)。

### 标签与备注

**备注**为单行短说明，`Ctrl + Enter` 保存，`Esc` 取消。

需要较长内容时点「**写详细说明**」，打开一份支持图文的说明文档，可包含多张图片和多段视频，面板上显示「N 张图」「N 段视频」。

### 导入依赖

列出该资产导入时带入的依赖。存在缺失时标注「N 个未找到」，超出显示范围时可「展开全部 N 条」。

点击某一条可「定位到所在文件夹」。该依赖不在当前保管库时提示「这个依赖不在当前保管库里」。

**设置 → 资产库 → 显示依赖资产** 可关闭该列表，关闭后只显示手动导入的资产。

### 修复资产依赖

资产右键菜单中的「**修复资产依赖**」会重新解析该资产的依赖关系。

## 依赖关系图

从资产右键菜单或详情面板的「查看依赖关系图」进入。

![资产依赖关系图](/shots/asset-dependency-graph.png)

图分三层：

| 层级     | 含义               |
| -------- | ------------------ |
| level -1 | 引用当前资产的节点 |
| level 0  | 当前资产           |
| level 1  | 当前资产引用的节点 |

左侧面板提供：

- **搜索节点** —— 按资产名称
- **层级过滤** —— 三层逐个勾选
- **类型过滤** —— 限定显示的资产类型
- **显示选项** —— 显示节点缩略图、显示缺失资产、启用物理约束
- **节点数量限制** —— 限制渲染的节点数
- **重置视图**

::: warning 节点被截断时关系不完整
顶部显示「已显示 N / M 个节点，关系不完整」，旁边有「全部显示」。此状态下，图中的连线不是完整的引用关系。
:::

点击节点后，右侧信息面板显示名称、类型、大小、路径、引擎版本，并提供「跳转到目录」。

外部引用的资产未入库时无法跳转，提示「外部引用资产未入库，无法跳转到目录」。

## 其他右键操作

| 菜单项                  | 说明                                       |
| ----------------------- | ------------------------------------------ |
| 捕获缩略图              | 从文件本身生成缩略图                       |
| 用作参考图生成          | 将该图加入 [AI 创作](/guide/aigc) 的参考图 |
| 打开本地路径            | 在资源管理器中定位                         |
| 跳转到所在目录          | 在库内定位                                 |
| 在文件管理器中打开      |                                            |
| 上传到百度网盘 / WebDAV | 见[百度网盘与 WebDAV](/guide/cloud-drive)  |

「打开本地路径」失败时提示具体路径，并指向保管库设置中的「浏览路径」。

## 默认打开方式

**设置 → 资产库 → 默认应用**，按类别指定：图片、视频、3D 模型、音频、代码、UE 资产。每一类可指定一个程序，也可恢复默认。

## 删除确认

**设置 → 资产库 → 删除确认** 控制删除文件或文件夹前是否询问。

此前选择过「不再提示」时，重新开启该开关可恢复确认弹窗。
