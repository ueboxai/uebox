# 工具、技能与权限

决定助手能碰什么、什么时候必须先问你。

默认值可以直接开工，不用先来这页调一遍。遇到「这类活我不想让它碰」、「每轮太贵」、「这个工程输不起」时再回来。

这页讲配置项。助手能做什么见[助手能做什么](/guide/capabilities)，这些开关在运行时怎么起作用见[助手是怎么干活的](/guide/agent-loop)。

## 工具

**设置 → 工具**。

![设置 → 工具](/shots/settings-tools.png)

### 清单按类别折叠

| 类别                 | 覆盖范围                                                          |
| -------------------- | ----------------------------------------------------------------- |
| **蓝图**             | 蓝图的图、成员、编译，动画蓝图                                    |
| **材质**             | 材质图、参数、实例                                                |
| **场景与关卡**       | 关卡中的 Actor、关卡本身、地形                                    |
| **内容浏览器**       | 查找资产、导入、重命名、移动、依赖、迁移、数据表                  |
| **编辑器**           | 视口、选择、保存、PIE、截图、输入与输入映射                       |
| **界面控件**         | UMG                                                               |
| **动画与过场**       | Sequencer、动画、网格                                             |
| **PCG 程序化**       | PCG 图                                                            |
| **C++ 与编译**       | 代码和构建                                                        |
| **系统与诊断**       | 控制台命令、Python、性能、崩溃、插件                              |
| **AI 生成**          | 生图、生视频、生 3D、任务转视频                                   |
| **虚幻盒子内置工具** | 素材库、蓝图/材质库、工程、本机文件与命令行、联网与浏览器、知识库 |
| **其他**             | 未归入上述类别的                                                  |

虚幻相关的工具按工作内容分类，应用自身的能力合并为一类。AI 生成单独成类：该类工具会按次向外部服务商计费。

### 工具搜索（Beta）

清单上方的「工具搜索（Beta）」开关，**默认开启**。开关决定清单里每个工具开关的含义：

| 状态           | 说明                                                   | 清单里的开关                                   |
| -------------- | ------------------------------------------------------ | ---------------------------------------------- |
| **开**（默认） | 按需提供：常驻一部分工具，其余由技能和搜索在需要时加载 | 控制该工具是否常驻                             |
| **关**         | 全部提供：每次对话带上全部工具                         | 控制该工具是否提供给模型，关闭的工具模型看不到 |

全部工具的定义约占 12 万 token（2026 年 10 月测量）。开启后只常驻一部分，其余不占每轮的上下文，长对话和带图的请求更不容易撞上服务商的长度上限。代价是模型需要先通过技能或搜索取回工具，可能选错或漏取。改动在下一次发消息时生效，不影响正在运行的任务。

### 开关

类别开关有三态：全开、全关、半开（组内部分开启）。半开状态下点击的结果是全开。

### 不可关闭的工具

**仅在关闭工具搜索时**，标记为「不可撤销」的工具无法关闭。这类工具由每一步的审批控制，不由本清单控制。开启工具搜索时它们可以设为不常驻，仍然能按需加载。

### 成本

清单上方显示「已开启 X / Y 个，每次对话约增加 N token」。开启工具搜索后变为「常驻 X / Y 个，每次对话约增加 N token；其余按需加载」。

### 第三方 MCP 的工具不在这里

第三方 MCP 服务带入的工具由 [MCP](/guide/mcp) 页面管理，不出现在本清单中。

## 技能

**设置 → 技能**。

![设置 → 技能](/shots/settings-skills.png)

技能是一段面向助手的做法说明，包含处理流程、已知问题和不适用的场景。

### 内置的 27 个

| 技能           | 范围                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 摆放 Actor     | 在关卡中放置、查询、移动、修改参数、删除                                                   |
| 关卡整理       | 将 Actor 归入大纲视图的文件夹                                                              |
| PCG 散布       | 程序化散布，以及排查产出为 0 个实例的原因                                                  |
| 地形           | 新建地形（平地或高度图）、配置颜色与高度 RVT、排查 RVT 无效果                              |
| 内容导入与整理 | 导入、查找、批量重命名、命名规范、依赖、迁移、数据表读写                                   |
| 蓝图图编辑     | 在已有蓝图中编辑逻辑与管理成员，含动画蓝图                                                 |
| 材质创作       | 创建材质、修改图、编译、实例、诊断                                                         |
| Substrate 材质 | 编写 Substrate 材质（UE 5.4+）、把工程切换到 Substrate                                     |
| 几何编辑       | 布尔、切割、简化、重拓扑、补洞、UV、碰撞                                                   |
| 动画重定向     | 骨架之间重定向、测量姿势、预览                                                             |
| UMG 布局       | 创建 Widget、放置控件、暴露变量、渲染预览                                                  |
| Sequencer      | 运镜关键帧、诊断渲染问题、修复 Camera Cuts、对比序列、重新绑定、用 Movie Render Queue 出片 |
| 白盒出概念图   | 截取视口画面传给生图模型                                                                   |
| 任务转视频     | 将对话和成果生成为本地视频                                                                 |
| C++ 工作流     | 新建类、改已有的类、编译并热重载、必要时完整重编                                           |
| 系统诊断       | 控制台命令、Python、性能、崩溃、ZenServer 缓存、插件                                       |
| 编辑器检查     | 视口、工程设置、关卡构成、引擎配置                                                         |
| 工程体检       | 体积、性能、资产问题审计，输出排序报告                                                     |
| AI 做 3D 资产  | 生图 → image-to-3D → 清理 → Blender 修形                                                   |
| 生图           | 生成和编辑位图                                                                             |
| Blender 互联   | 导出到 Blender 修形再导回                                                                  |
| 资产库         | 检索和整理素材库                                                                           |
| 知识库与工程   | 存取知识库、创建工程、整理工程库、导入资产                                                 |
| 本机文件       | 列目录、查找文件、搜索内容、读写、执行 shell                                               |
| 深度研究       | 拆分问题、检索、读取页面、输出带引用的报告                                                 |
| 技能创作       | 将做法写成技能，或修正错误的技能                                                           |
| 提反馈         | 将过程中的阻碍整理成缺陷报告                                                               |

每条技能的适用与不适用范围见[助手能做什么](/guide/capabilities)。

### 来源与开关

三种来源：**内置**、**插件**、**自定义**（你编写的，或助手自动保存的）。清单可按来源筛选，也可搜索名称和说明。

每条可单独开关，下次任务生效。关闭的显示「已关闭」标记。

点开可查看正文，也可编辑：

- 编辑「自定义」技能会直接更新原文件
- 编辑内置技能会保存为自定义副本，应用更新不覆盖该副本；删除副本后恢复原版

「打开技能目录」跳转到对应文件夹。

工程也可以自带技能：放在 `<工程根>/.uebox/skills` 下，技能里的 Python 脚本可以按路径直接运行。

::: danger 删除技能不可恢复
删除操作会移除该技能的整个目录，不会进回收站。删除自定义副本只是恢复原版，不影响内置内容。
:::

读取失败时显示「读取失败：{原因}」，不显示为 0 条。

### 自动记录做法

助手把验证过的做法存成技能，把遇到并已解决的问题记入经验库，供下次同类任务使用。默认「**先确认**」：保存技能前先问你。

| 档位               | 技能       | 经验                             |
| ------------------ | ---------- | -------------------------------- |
| **关闭**           | 不保存     | 不记录；已有经验保留，但不再提示 |
| **先确认**（默认） | 保存前确认 | 自动记录与淘汰                   |
| **自动**           | 保存后通知 | 自动记录与淘汰                   |

写入文件这一步仍受权限控制。关闭时，清单上标记「自动记录已关闭，技能未启用」。

### 经验库

**设置 → 经验库** 列出助手记下的经验，每条显示做法、触发条件（报错里含哪段文字）、适用范围（所有工程或仅限某个工程）、适用的引擎版本，以及提示、采用、成功的次数。

- 状态分「试用中」、「已验证」、「已淘汰」，淘汰的默认隐藏，勾选「显示已淘汰」查看。
- 可按「通用」、「工程」筛选；每条可固定（不自动淘汰）或删除。
- 「撤销上次整理」把经验库恢复到上一次整理之前的状态。

机制见[助手是怎么干活的 · 经验](/guide/agent-loop#经验)。

## 权限

### 对话级：审批模式

在输入框下方切换，每条对话独立记录。四档，见 [AI 对话 · 审批模式](/guide/assistant#审批模式)。

### 全局：文件访问范围

**设置 → AI 助手 → 隐私 → 文件访问范围**。默认「整台电脑」，因为很多正经活（读一份外部表格、翻一个参考工程）都在 UE 目录之外。机器上有不想让助手看见的东西时再收窄。

| 档位                 | 范围                                                 |
| -------------------- | ---------------------------------------------------- |
| **整台电脑**（默认） | 本机文件，不含受保护的敏感目录                       |
| **仅虚幻相关**       | 已安装的引擎、已导入的工程、素材库；同样排除敏感目录 |

两档都排除敏感目录。该设置**不限制 shell 调用**，兜底的是敏感目录黑名单和每一步的审批。

调成「仅虚幻相关」后，助手够不着某个路径时会收到说明并告诉你。

### 全局：允许编辑器截图

控制助手能否获取虚幻编辑器画面。关闭后助手只能通过查询接口获取场景信息。

### 全局：浏览器

在 **设置 → AI 助手** 中：

| 设置                     | 默认     | 说明                                                                       |
| ------------------------ | -------- | -------------------------------------------------------------------------- |
| **浏览器显示方式**       | 嵌入助手 | 嵌入助手 / 独立窗口 / 隐藏                                                 |
| **允许浏览器访问局域网** | 关       | 开启后助手可以打开本机和局域网地址（如 localhost），用于查看本地开发服务器 |

::: warning 「隐藏」只影响显示
隐藏画面不改变操作权限，助手仍可访问和操作网页。
:::

### 全局：修改资产时设为只读

**设置 → AI 助手 →「修改资产时设为只读」**，默认关。开启后，助手改资产期间把对应的 `.uasset` 设为只读，防止你在编辑器里保存时覆盖它的改动；代价是这些资产在编辑器里暂时无法保存。工程启用版本控制时不生效。另一条对话同时改同一个资产的冲突不受这个开关影响，始终拦截，见[资产锁](/guide/agent-loop#资产锁)。

### 全局：已设为始终允许的操作

审批卡片上点过「以后均允许」的工具，列在 **设置 → AI 助手 → 已设为始终允许的操作**。这些操作在所有对话里不再询问，只读对话不受影响。点每项右边的「移除」恢复询问。

## 审批

- 确认请求超过五分钟未响应按拒绝处理，提示「确认请求超时，操作已取消」。
- 「需要确认时提醒」默认开启，见[通知](/guide/small-tools#通知)。
- 「本对话内均允许」只在当前对话有效；「以后均允许」对所有对话有效，可移除。
- 并行执行时可能同时有多条待确认项，逐条弹出，并显示「还有 N 项待确认」。
- 改档位**当场生效**：被确认框拦住时把档位调松，本轮就少弹框，不必等下一条消息。
- 少数操作**每次都要当场批准**，没有两个「允许」按钮，例如往网页里点击和输入。选了「完全访问权限」后这些操作也不再弹确认。

操作被拒绝后，助手换一种做法或者问你希望怎么做；你再次明确要求时，它会再次发起。

## 给助手交代背景

**设置 → 个性化 → 给助手的说明**。

这段说明应用于所有对话，用于描述工作内容、技术背景和沟通偏好。界面上给出的示例：

> 我是游戏公司的地编，主要做大世界场景搭建和优化。
> 我不写 C++，蓝图能看懂但不熟，别默认我会。
> 结论先说，过程我需要的时候会问。

也可以点「用默认文本编辑器打开」在外部编辑。该文本存在应用数据目录的 `instructions.md`。
