# 快捷提问（Spotlight）

两个悬浮窗口，不用切回主界面也能用：**Spotlight** 用来搜索项目和资产、把一句话转给 AI；**小窗**（MiniChat）是一个浮动的 AI 对话窗口。

## Spotlight

一个悬浮搜索框。快捷键在 **设置 → 快捷键 →「呼出/隐藏快捷提问窗口」**，默认 `Ctrl+Shift+Space`。

窗口固定 600×400，记住上次拖动到的位置，输入框左侧的四向箭头是拖拽手柄。点击窗口外或窗口失焦时自动收起。

### 结果

输入内容后最多显示 11 条：

| 段         | 条数   | 选中之后                                       |
| ---------- | ------ | ---------------------------------------------- |
| 与 AI 对话 | 1      | 打开小窗，带着这句话继续对话                   |
| 项目       | 最多 5 | 直接打开对应的 `.uproject`                     |
| 资产       | 最多 5 | 跳转到「资产管理」并定位到这份资产所在的文件夹 |

项目按名称搜项目库，资产按名称搜**当前活跃的**资产库。上下箭头切换，回车执行。

::: tip 选中「与 AI 对话」时会抓取一次编辑器状态
按下回车即发送，快照在这一刻抓取，不等小窗打开。打开小窗要半秒多，这段时间里你可能已经切回引擎换了选区。

抓取和开窗并行进行。抓到的快照随消息一起带入；抓不到也照常发送，不会等待。
:::

### 语音下指令

按热键说一句话，Spotlight 把它转写后交给 AI。

- 开启：**设置 → 快捷键 →「语音下指令」**。默认关闭，默认键 `Alt+Q`（全局热键）。
- 按下热键，Spotlight 打开并开始收音。**按住不放**，松开时发送（提示「松开即发送」）。**点一下**则说完后倒计时 2 秒自动发送（提示「N 秒后发送，编辑内容可延后」），倒计时内修改文字会推迟发送，按 `Esc` 取消，同时关闭麦克风。
- 需要「语音识别」模型：**设置 → 模型 → 默认模型 → 语音识别**（内置豆包 STT 2.0、阿里云 Qwen-Audio ASR、硅基流动 SenseVoice，也可接本机运行的 SenseVoice、Whisper 等服务：Gradio 网页版直接填浏览器里打开的地址，如 `http://127.0.0.1:7860`；OpenAI 兼容的填到 `/v1`）。后两类不边说边出字，每停顿约 0.8 秒出一句。未配置时回退到实时语音通道，该通道仅 OpenAI `gpt-realtime` 可用；绑定的是豆包实时语音时提示「当前语音模型仅支持对话；在 设置 → 模型 中绑定「语音识别」模型后即可听写」。
- [语音通话](/guide/voice)正在进行时麦克风被占用，提示「语音助手正在通话中，请使用键盘输入」，此时退回键盘输入。

## 小窗

小窗（代码里叫 MiniChat）是一个独立的悬浮对话窗，400×600，默认置顶。标题栏上可以切换置顶、最小化、关闭。

它是完整的 Agent 窗口：输入框提示「给 Agent 下达任务…」，能调用工具、执行任务。

### 三个入口

| 入口                       | 打开的是什么                               |
| -------------------------- | ------------------------------------------ |
| Spotlight 的「与 AI 对话」 | 带着那句话和编辑器快照开一段新对话         |
| `Ctrl+Shift+M`             | 直接开关小窗                               |
| AI 对话里的「侧边问一句」  | 带着主对话上下文开一个**只读**的窗口，见下 |

::: warning `Ctrl+Shift+M` 不在快捷键设置里
这个组合是固定的，不能修改，也不在 设置 → 快捷键 的列表中，但「全局禁用快捷键」总开关对它有效。

按了没反应时，通常是这个组合被别的软件占用了。
:::

### 附件

最多 5 张图片，单张 20 MB 以内。

### 消息操作

复制、重新生成 AI 回复、编辑自己发过的消息。

::: tip 窗口透明度和对话历史不能设置
代码里有这两项的设置面板，但目前被特性开关关闭，设置里看不到。透明度固定为不透明，小窗里的对话固定保存。
:::

## 侧边问一句

在 AI 对话里点「**侧边问一句（带上下文）**」，会把当前对话的上下文**复制**一份到小窗里，在那边提问。

适用场景：Agent 已经跑了二十步，你想问「它现在在做什么」「刚才那个材质为什么建了两次」。在主对话里问这句有两个代价：

- 要等 Agent 停下来才能问。
- 这句话会一直留在主对话的上下文里，之后每一轮请求都带着它。

在侧边窗口里提问没有这两个代价：问完关掉，主对话不会收到任何内容。

::: danger 侧边窗口是只读的
侧边窗口固定使用只读模式，只注册只读工具。它能查看、检索、解释，**不能修改工程**。
:::

窗口顶部的横幅说明三件事：借了多少条上下文、这是快照还是实时、这边只读。主对话还在运行时，横幅写「承接主对话的 N 条上下文（快照，主对话仍在运行）」。

当前对话里还没有 Agent 运行过时，点击会提示「暂无可带入的上下文」，不会打开窗口。
