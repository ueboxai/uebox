# 资产库：团队协作

几个人共用一个资产库，有两种做法：

| 做法             | 适合                       | 服务端                     |
| ---------------- | -------------------------- | -------------------------- |
| **SMB 共享**     | 人数少、临时协作           | 不需要，一台机器共享文件夹 |
| **服务器资产库** | 团队长期使用，需要权限管理 | 管理员部署资产服务器       |

服务器资产库见[服务器资产库](/guide/asset-server)。这一页讲 SMB 共享。

## SMB 共享

一台机器作主机，其他人填写共享路径连接，例如 `\\192.168.1.100\Assets`。入口：新建资产库 →「网络协作库」→「SMB 共享」。「网络协作库」默认显示，可在 **设置 → 资产库 → 高级** 里隐藏。

填写路径后，应用会检测一次，结果有五种：

| 提示                   | 含义                 |
| ---------------------- | -------------------- |
| 路径可访问，有写入权限 | 能读能写             |
| 路径可访问（只读）     | 只能看               |
| 需要认证               | 要填凭据，见下       |
| 路径无法访问           | 路径或网络有问题     |
| 检测失败               | 检测这一步本身没跑成 |

### 网络认证

需要认证时会弹「网络认证」：用户名（`域\用户名` 或 `用户名`）和密码。勾「记住凭据」会**加密保存在本地**。

### 主机访问码

主机那台机器在保管库设置里能看到两个码：

- **浏览码（只读）**
- **管理码（可写）**

把码发给同事，他们在连接时填上就能用。

也可以勾选「**允许共享目录中的同事写入**」。勾选后，能访问该共享文件夹的电脑自动获得写入权限，无需填码。

::: warning 重新生成会让所有人掉线
「重新生成」之后，所有用旧码连接的电脑都会掉线，需要重新填码。
:::

填错码时的提示是「资产库访问码不正确，请向主机确认」；没填是「需要资产库访问码，请向主机索取配对码后填写」。

## 同步

### 实时推送

连接期间通过长连接实时推送：其他成员上传资产、修改标签、移动文件夹后，本地列表自动更新，不需要手动刷新。

工具栏上还有两个手动动作：

- **拉取同步** —— 从服务器拉取最新变更
- **扫描变更** —— 扫描服务器上的文件变更

### 断网时

改动记在本地排队，界面上会写出来：

| 提示                                                 | 含义               |
| ---------------------------------------------------- | ------------------ |
| 已保存到本地，但未连接到资产服务器，N 条改动待同步   | 断线了，排着       |
| 已保存到本地，但推送到资产服务器失败，N 条改动待同步 | 连着但推送失败     |
| 有改动无法同步到资产服务器，请检查冲突               | 卡在冲突上了，见下 |

网络恢复后，排队的改动会自动推送。

主机离线时页面上会显示「主机离线」和「重试连接」。

## 版本冲突

多人修改同一份索引时弹出「**版本冲突**」，显示双方的版本、修改者和修改时间，需二选一：

| 选择             | 后果                                         |
| ---------------- | -------------------------------------------- |
| **使用远程版本** | 放弃本地未同步的修改，用服务器上的最新版本   |
| **覆盖远程版本** | 用本地版本覆盖服务器，**其他人的修改将丢失** |

选覆盖时弹窗会再提示一次「此操作将覆盖远程修改，请确认您了解风险」。

## 删除的差别

在网络协作库里删东西和在本地库里不是一回事：

| 操作         | 本地库                 | 网络协作库                                           |
| ------------ | ---------------------- | ---------------------------------------------------- |
| 删文件夹     | 进「最近删除」，可恢复 | **共享盘上的目录一并删除，全队失去，无法恢复**       |
| 删保管库本身 | 永久删除文件和数据库   | 只移除本地连接记录和缓存，**不动网络位置上的源文件** |

## 缓存

网络库的缩略图会缓存在本地。保管库菜单里的「清除缓存并重新加载」可以清掉，会报清了多少张、释放了多少 MB。

缺少写入权限时清不了，会明说「网络库缺少写入权限，无法清理缓存」。
