# 笔记与知识库

导入一批资料，针对这批资料提问，回答引用其中的内容。

侧边栏「更多」里有两项独立功能：

- **笔记** —— 文本记录
- **知识库** —— 导入一批资料后针对其提问，并生成派生内容

两者也是 Agent 的资料来源：对话可以绑定知识库（`/wiki`），Agent 从中检索材料，并把深度研究的结果写回去。外部 MCP 客户端没有绑定的对话，检索范围是盒子里的全部知识库，见 [MCP](/guide/mcp#外部客户端能用什么)。

![知识库列表](/shots/notebooks.png)

## 笔记

块编辑器，输入 `/` 打开命令菜单：标题、项目符号列表、编号列表、待办列表（带复选框）、引用、代码块、表格、分割线。

AI 对话里的回复可以直接保存成笔记。

![笔记编辑器](/shots/note-editor.png)

::: tip 笔记也是知识库的一种来源
笔记没有单独的存放位置，它是知识库里的一种来源类型。在 AI 对话里用 `@` 可以提及某条笔记。
:::

## 知识库

### 列表页

分类：**全部** / **我的知识库** / **精选知识库**。可以按最近或名称排序，网格视图或列表视图切换。

每个库显示来源数量和生成数量。

新建、重命名、删除（**不可恢复**）、上传封面（图片不超过 5 MB）。

### 一个知识库里有什么

三块：**来源** + 针对来源的**对话** + **工作台产出**。

## 来源

### 加来源

点「添加来源」，支持的类型：

| 类型         | 说明               |
| ------------ | ------------------ |
| **Web**      | 网页               |
| **YouTube**  |                    |
| **Bilibili** |                    |
| **文本**     | 直接粘，或添加笔记 |
| **文件**     | 本地文件           |

还能直接从已连接的 UE 工程里抓：

- **项目信息**
- **UE 崩溃日志**
- **UE 项目配置文件** —— 引擎配置 / 游戏配置 / 编辑器配置 / 输入配置

适用于排查崩溃和核对配置。

::: warning 音频只存不转写
音频会作为附件保存，可以打开原文件播放，**暂不提供音频转写**。
:::

### 在网络中搜索新来源

来源面板上的「在网络中搜索新来源」：输入检索内容，结果支持多选，通过「添加选中项」批量加入。

旁边的「输入想深度研究的问题」入口走[深度研究](/guide/capabilities#应用自身)流程。

### 网页清洗

网页抓取后会清洗一次，去掉导航、广告等噪音。每条来源可以在「**查看原文**」和「**查看清洗结果**」之间切换；原文视图下提示「此为抓取的原文，AI 使用清洗后的版本」。

清洗失败时的提示：

| 提示                                                                 | 含义                             |
| -------------------------------------------------------------------- | -------------------------------- |
| 「{标题}」网页清洗失败，已使用抓取的原文                             | 清洗没成，退回原文，仍然可用     |
| 页面过长：当前「轻量任务」模型单次最多输出 N token，无法完成整篇清洗 | 受「轻量任务」模型的输出上限限制 |
| 模型没有返回内容                                                     | 清洗没有结果                     |
| 清洗结果仅 N 字（原文 M 字），疑似输出中断，未采用                   | 结果可疑，**没有采用**           |

### 网页里的图片

**设置 → 知识库 → 网页导入 → 读取网页里的图片**。开启后会识别网页图片中的文字并标注为「**AI 识别**」，原文不改动。

完成后提示「已从 N 张图片中识别文字（标注为「AI 识别」，原文未改动）」。

::: warning 默认关闭，因为会产生模型费用
开启后还能限制每篇最多识别几张。
:::

## 上下文档位

每条来源可以设定这次送多少内容给模型：

| 档位           | 说明       |
| -------------- | ---------- |
| **全文**       | 整篇送进去 |
| **仅摘要**     | 只送摘要   |
| **不进上下文** | 这次不用它 |

点来源上的标签，在「全文」和「仅摘要」之间切换。也可以批量设置：全部使用全文 / 全部仅摘要 / 全部不进上下文。

面板实时显示预算：「本次送入 X字 / 上限 Y字 · N 个来源」。

超出上限时，提示点名无法送入的来源：

> 超出上限，N 个来源本次无法送入：{标题}。请将其改为「仅摘要」或取消勾选。

摘要尚未生成的来源，本次送入正文开头，并提示点击该来源的「摘要」标签可立即生成。

## 索引与召回

### 建索引

知识库检索需要**嵌入模型**：设置 → 模型 → 默认模型 → **嵌入**。未配置时检索不可用。

来源面板上的「索引选项」里有：

- **编辑后自动索引** —— 改完笔记自动更新
- **更新索引** —— 手动跑一次

设置 → 知识库 → 数据管理里还有「**重建知识库索引**」。

::: warning 更换嵌入模型会自动重建整个索引
库大的话要等。用 Ollama 的本地嵌入模型可以避免云端费用。
:::

### 测试召回率

来源面板上有「**测试知识库召回率**」：输入一段内容，看它能召回哪些片段。

结果列出三项：**匹配距离**、**关键词命中**、**来源**。

回答不准时，先用它判断问题出在检索没召回，还是召回了但模型没用好。

## 提问

添加来源后即可针对这些内容提问，回答会引用具体来源（「参考资料」）。入口是知识库页面里的「与知识库对话」。

可以「全选 / 取消全选」来源，界面显示「应用了 N 个来源」。一个都没选时提示「请至少选择一个来源」。

## 工作台

把这堆资料转换成别的形态：

| 产出         | 说明                                                                                                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **思维导图** | 结构化的树                                                                                                                                                                               |
| **知识图谱** | 概念关系网。节点分类贴 UE：类 / API、功能 / 系统、节点、资产类型、工作流、格式 / 标准、设置 / 属性、工具 / 软件、平台、插件、问题 / 报错、解法、概念。关系有「是一种」「包含」「属于」等 |
| **总结报告** | 一篇文字总结                                                                                                                                                                             |
| **信息图**   | 一张图讲清楚，可下载、复制到剪贴板                                                                                                                                                       |
| **知识网页** | 可浏览的页面。分两步生成：先出 Brief，再照 Brief 排版                                                                                                                                    |
| **模拟面试** | 基于资料出题考你，逐题给 AI 点评和参考答案，结束后有答题回顾和得分                                                                                                                       |
| **头脑风暴** | 围绕资料发散想法                                                                                                                                                                         |

产出可以按类型、状态（生成中 / 已完成 / 失败）、时间（今天 / 近 7 天 / 更早）筛选，也可以按最新 / 最早 / 名称排序。

::: warning 生成会产生模型费用
提示「模型服务商返回「余额不足」」时，是所配置服务商的账户余额问题，需到该服务商的控制台充值，或在 设置 → 模型 更换模型。
:::

## 在 AI 对话里用知识库

不切到知识库页面也能用：

- `/wiki [关键词]` 把一个知识库绑定到当前对话，`/wiki clear` 解绑
- `@` 提及某条来源或笔记

见 [AI 对话 · 斜杠命令](/guide/assistant#斜杠命令)。

## 让助手去查，查完存进来

知识库页面没有「网页」和「深度搜索」页签。查资料直接在对话里说：

> 查一下 X，有用的存进来

助手会拆分子问题、检索、**读取页面正文**、对照已有来源、处理来源之间的冲突，然后把值得保留的内容存成来源。

- 使用你配置的对话模型和内置浏览器，不需要第三方研究服务的密钥。
- 存来源属于需要审批的操作：「请求批准」模式下每存一条都会请你确认，「帮我批准」模式下自动通过。
- 对话没有绑定知识库时，存入会新建一个知识库（标题默认取来源标题）。要存进已有的库，先用 `/wiki` 绑定。
- 外部 MCP 客户端调用时，可以用 `notebookTitle` 指定知识库标题：盒子里有同名知识库就存进去，没有才新建。

::: tip 研究报告的几条规则
这些写在助手的做法说明里，核对它的产出时可以参照：

- 只引用它实际打开过的页面，搜索结果摘要不算。
- 没查到时如实说明哪个子问题没有答案，不编造。
- 区分信息来源的身份：论坛里用户的猜测，和维护者的说明，不按同一种证据对待。
- 它之前写进知识库的总结不当作来源；检索到时回到原始页面重新核对。

:::

::: warning 三种查不动的情况

- **登录墙和验证码**：不会绕过，转去找公开来源，或如实报告缺口。
- **纯 JavaScript 渲染的页面**：读回来的正文是空的。助手会去找内容相同的静态页，不会据此判定这个话题没有资料。
- **检索后端出问题**：搜索一直返回不相关结果时，助手会说明并停止。这种情况和「这个话题没有答案」表现相同，需要你自己判断。

:::
