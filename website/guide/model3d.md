# 3D 生成与查看器

不开引擎就能查看模型，也可以在盒子里让助手生成模型。

## 3D 查看器

侧边栏「更多」里的 **3D 查看器**。把模型文件拖进来，或点右上角「选择模型文件」。

支持 `.fbx`、`.obj`、`.glb`、`.gltf`。其他格式会提示「请上传 FBX, OBJ, GLB 或 GLTF 格式的文件」。

![加载了一个模型：左边视口，右边是光照、视角和模型信息](/shots/model-viewer-loaded.png)

![3D 查看器](/shots/model-viewer.png)

### 显示模式

工具栏上可以切换：

| 模式     | 看什么           |
| -------- | ---------------- |
| **默认** | 带材质的正常渲染 |
| **法线** | 法线方向         |
| **线框** | 拓扑结构         |
| **白模** | 去掉材质看形体   |
| **UV**   | UV 展开          |

另外两个开关：**自动旋转**、**播放动画**（模型带动画时）。

![线框模式](/shots/model-viewer-wireframe.png)

### 光照与视角

右侧面板还有两组：

**光照** —— 三个预设：**影棚** / **日光** / **暗房**，下面一条**亮度**滑块。看深色模型时切到日光通常更容易看清形体。

**视角** —— 两个按钮：

- **回到默认视角**
- **修正模型朝向（切换向上轴）** —— 有些导出的模型向上轴和 UE 不一致，进来是躺平的，点它转正

### 模型信息

右侧面板列出：文件格式、文件大小、顶点数、面数、材质数、网格对象、贴图数、包围盒。

可用于检查模型面数和材质槽数量。

### 截图更新缩略图

工具栏的「**截图更新缩略图**」把当前视角截下来当这份资产在资产库里的缩略图。

模型不在资产库里时不能更新，提示「该模型不在资产库中，无法更新缩略图」。

## 3D 生成

::: warning 没有独立的界面入口
3D 生成、视频生成这两项**没有专门的页面或按钮**，通过在 [AI 对话](/guide/assistant)里用自己的话要求来触发。

比如：「照着这张图做个底模」「生成一个石头的模型」。
:::

生成的模型显示在助手回复里生成它的那组步骤下面，可以直接转着看。

### 配置

**设置 → 模型 → 添加服务商 →「3D 生成」分组**。支持三种接口：

- **Hyper3D Rodin**
- **Tripo（VAST AI）**
- **Meshy**

添加模型时要勾「**3D 生成**」能力，并在模型设置里选对应的 **3D 接口**，然后按服务商的说明填模型 ID。没选接口时无法生成。

最后在「默认模型 → 3D 生成」里指向它。

### 费用

::: danger 生成可能几分钟，失败也可能扣费
计费规则以服务商为准。视频生成同理，而且单次更贵。
:::

### 重做需要用户确认

生成图片、视频、3D 模型均按次计费，结果是否符合预期由你判断。助手认为结果不理想时会询问你，不会自行重新生成。

### 结果去哪

生成的网格存进素材库 `AIGC/模型` 目录，助手回复里给出文件路径；需要进工程时再用导入工具导入。

失败或超时都会写明是哪一种：

- **失败**：给出错误信息。
- **超时**：模型可能仍在生成中，可以稍后查询任务状态；状态未知时不要直接重发，重发会再扣一次费。

### 出来的是静态网格

图生 3D 的结果没有骨骼，不能直接做动画。提示词里写 T-pose 并去掉底座，只是让人形摆成方便之后绑定的姿势。

### 自动绑骨：`rig_3d_model`

对 **Tripo** 生成的角色或动物，助手可以用 `rig_3d_model` 自动绑骨：

- 输入是那次生成的任务号（`job_id`），不需要把模型文件传回去。
- 先免费检查能不能绑，能绑才提交。**绑骨另外计费（约 30 额度），失败也扣。**
- 骨骼类型：双足、四足、六足、八足、有翼鸟类、蛇形、水生。不指定时按厂商检查后的推荐。
- 默认使用 Mixamo 骨骼命名、输出 FBX，导入时按骨骼网格（`skeletal_mesh`）处理。
- 只出带骨架的网格，没有动画。要让它动，用 `anim_retarget` 把工程里现有的动画重定向过来。
- 其他服务商（Rodin、Meshy）生成的模型，以及工程里已有的网格，不能用它绑，需要在 Blender 等软件里手动绑。

## 从想法到模型的完整路子

单独一次 image-to-3D 通常做不出可用的资产。助手有一个专门的技能（`ai-3d-asset-production`）把几种能力串起来：

1. 生图：概念图和互相一致的四视图
2. image-to-3D：出底模
3. 引擎内处理：Geometry Script 做减面、补洞、UV；`mesh_optimize` 生成 LOD 和碰撞
4. Blender：复杂改形（Windows 和 macOS，见 [MCP · Blender](/guide/mcp#blender)）

动手前先对着参考图写一份验收清单；每一段结束都按清单核对，通过再进下一段。

::: tip 两个已知的坎
用 Blender 堆基本体做不出有机造型；同一个缺陷连续三次没修好，继续改往往越改越差。技能要求每一轮都对着原始参考图逐条核对，连续三次不通过就换方法。
:::

详见[助手能做什么 · 素材生产](/guide/capabilities#素材生产)。
