# 出问题了

按症状找。找不到的话，日志在应用数据目录的 `logs/` 下，见[文件都放在哪](/guide/where-is-my-data)。

## AI 功能

### 界面提示「添加服务商，并选择『对话』默认模型后即可使用 AI」

还没配置模型。见[配置模型](/guide/ai-setup)。

### 「模型服务商返回『余额不足』」

**所配置服务商**的账户余额不足。到该服务商的控制台充值，或在 设置 → 模型 更换模型。

应用本身没有账户，不涉及应用的收费。

### 「API 密钥无效或已过期」

设置 → 模型，检查该服务商的密钥。复制时带了空格是最常见的原因。

### 「无法安全保存密钥，请通过环境变量提供密钥」

系统的加密存储不可用。把「API 密钥」改成填写环境变量名，或 `!` 开头的取密钥命令，见[密钥的三种填法](/guide/ai-setup#密钥的三种填法)。

### 测试连接失败

各条报错的含义见[测试连接失败](/guide/ai-setup#测试连接失败)。盒子自己发出的网络请求跟随系统代理，请求超时先确认代理设置。

### 订阅登录失败或反复要求登录

- Codex、Kimi Code、CodeBuddy / WorkBuddy 的令牌会自动续期。续期失败时，在 设置 → 模型 里点「重新登录」
- ZCode 没有刷新接口，令牌失效后必须重新登录
- 登录过程中提示平台要求重新验证（ZCode），先在 ZCode 官方页面完成验证，再回来重试
- 登录窗口长时间没动静，点「等待浏览器授权… 点此取消」重来。同一时间只能进行一次登录

### 「模型连接中断，N 秒后自动继续」

模型请求被中途掐断时，盒子会自动续跑，最多两次（间隔 10 秒、30 秒），已完成的步骤不会重复执行。

模型服务反复失败时，若 设置 → AI 助手 →「自动断点续传」开着（默认开），会每 60 秒从断点继续，连续失败 30 分钟后停止。服务商持续无响应的话，停止后换一个模型或渠道。

### 生图/视频类服务商测不了

这类接口调用即产生费用，所以不提供测试。界面会显示「连接测试会产生生成费用，因此不提供；首次生成时会验证配置」。**这不等于测通了** —— 第一次真用的时候才知道。

### 发送图片报错

主模型不支持识图，且没配「视觉」默认模型。换一个支持视觉的对话模型，或在 设置 → 模型 → 默认模型 → 视觉 指定一个。

### 「这条对话还有一轮在跑」

等它结束，或者直接在输入框发下一步的说明。不需要找「停止」再重发。

### 上下文满了

输入框附近的「上下文 X / Y」到顶会自动压缩。也可以手动 `/compact`。

无法压缩时会说明原因，见 [上下文窗口](/guide/assistant#上下文窗口)。

### 选了某个思考档位但没生效

提示「{模型} 没有 {所选} 这一档，本次实际按 {实际} 执行」。每个模型支持哪几档由它自己声明。

### Agent 说做完了，但实际没有

用「**审查**」到引擎中核实，再查看「自证」回复，见[结果核对：三层](/guide/assistant#结果核对-三层)。

### 同一个操作试了几次就不试了

同一个工具、一字不差的同一组参数连续失败，会被拦下，防止 Agent 无限重发一个必然失败的调用：

- 一般工具：连续失败 2 次
- 编译、试玩、截图、打包、执行命令这类结果随工程状态变化的工具：连续失败 5 次
- 中间只要有一次成功的写操作（改了文件、资产或工程），所有失败计数清零

换个说法让它用别的参数或别的路子重试即可。见[四道护栏](/guide/agent-loop#撞墙熔断)。

### 界面上显示「AI 锁定了 N 个资产」

Agent 修改一个资产时会锁住它，防止另一条对话同时改同一个资产。被挡的那条对话会收到「{资产} 正被「{对话}」修改，本次未改动」。点开指示器可以看到锁了哪些、被哪条对话锁着，旁边有「**全部解锁**」。

任务跑完锁会自动释放；应用进程崩溃后，锁表随之消失，不会留下残留的锁。见[资产锁](/guide/agent-loop#资产锁)。

### UE 里保存资产报「文件只读」

只有开启了 设置 → AI 助手 →「修改资产时设为只读」才会出现，这个开关**默认关闭**。开启后，Agent 修改资产期间，对应的 `.uasset` 会被设为只读，你在编辑器里的保存会失败，改动仍在编辑器内存里，不会丢。

等 Agent 做完，或在指示器上点「全部解锁」，或直接关掉这个开关。

::: tip 工程启用了版本控制时不会出现这种情况
只读位归 Perforce 之类的版本控制管，盒子不碰它。
:::

### `/goal` 跑满轮数还没做成

目标模式默认最多迭代 10 轮，到顶就停下来交给你。目标确实需要更多轮的话，去 **设置 → AI 助手 →「目标模式最大轮数」** 调高（范围 1–50，下一条消息起生效）。

如果第一轮就停了并说验不了，那是 `BLOCKED` —— 审计员够不着要验的东西（引擎没连上，或者这个目标交付的是一段回答而不是可查的状态）。这种情况再催多少轮都一样。见[目标模式](/guide/agent-loop#目标模式)。

### 敲了 `/goal` 但没进目标模式

对话挂在**只读**档时不进目标模式 —— 干活那一路什么都改不了，「只读」和「迭代到达成」本来就互斥。这一轮会按普通对话完整跑完，界面上会说一声。

### 拖进视频后，模型说看不到

- 对照[视频和音频](/guide/assistant#视频和音频)的三个条件：配好对象存储、模型勾了「视频」能力、走 OpenAI 兼容协议。缺一样，Agent 就会改用工具去看
- 时间线里有「传到对象存储失败」的提示的话，后面跟着原因。对象存储的各种报错见[对象存储 → 出问题了](/guide/object-storage#出问题了)
- 桶开了防盗链或 IP 白名单，厂商会下载失败

### 发送后报错，提到 video_url 或 input_audio

这家厂商支持视频，但不接受这种传法，或者不接受音视频和工具调用出现在同一个请求里。把完整报错发到 [GitHub Issues](https://github.com/ueboxai/uebox/issues)。在那之前，可以先在「设置 → 模型」里取消这个模型的「视频」能力，退回用工具看视频。

## 引擎连接

### Agent 看不到引擎里的内容

按顺序查：

1. 虚幻编辑器开着吗
2. 设置 → 插件 → 连接状态，「引擎桥接」是不是「正常」
3. 「已连接的工程」是不是 0 —— 是的话，多半是那个工程没装插件。项目库里工程卡片右键 →「安装桥接插件」。插件确认装了还是 0，看下一条

插件会自动连接，断开后每 5 秒重试一次，不需要手动操作。

插件版本太旧、缺命令，或者没装上时，Agent 会调用 `project_update_plugin`：经你审批后，关编辑器、装插件、重新打开工程。编辑器里有未保存的改动时它会先拒绝，请先保存。见[连接虚幻引擎](/guide/plugin#插件太旧或没装上时-agent-自己处理)。

### 编辑器崩溃后又自己打开了

Agent 的命令在等结果时编辑器崩溃，盒子会告诉 Agent 崩溃原因，由 Agent 决定是否重开。重开时会关掉崩溃报告窗口，并把未保存的自动存档备份到工程的 `Saved/UEBoxCrashRecovery`。5 分钟内再崩一次就不再重开。你自己操作时发生的崩溃，盒子不会处理。

不想要这个行为：设置 → 插件 → 关掉「允许 Agent 重开崩溃的编辑器」。

### 编辑器很慢或疑似卡住

打开对话页顶栏的「状态监控」，看哪几项偏离预期（编辑器卡顿率、资产注册表扫描、可用内存等），点「问 AI」让 Agent 排查。工程里的插件太旧时，面板会提示先更新插件，见[连接虚幻引擎](/guide/plugin#编辑器状态与崩溃)。

### 插件装了、编辑器也开着，「已连接的工程」还是 0

先看 UE 日志（`<工程>/Saved/Logs/<工程名>.log`）里有没有 `LogUALNetwork: Error: Connection error`。有的话插件是加载了的，卡在网络这一步 —— **不用重装插件，也不用停用别的 MCP，端口冲突不是这个现象**。

最常见的原因是**代理**。虚幻的 WebSocket 实现会把系统代理套到所有连接上，**不对 localhost 例外**，所以 UE 连本机的盒子也会被送进代理，代理拒绝就成了这个样子。日志里紧跟着会有插件报出来的那句代理提示（带查到的变量和地址）；启动日志里 `bUseHttpProxy=true` 是同一个信号。

启动编辑器时绕开代理：

```
UnrealEditor.exe <工程>.uproject -ini:Engine:[HTTP]:HttpProxyAddress=
```

同时在启动 UE 的那个环境里清掉 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY`（大小写两种都要）。连上后 UE 日志会出现 `Connected to ws://127.0.0.1:17860`。

注意无代理启动会让这个 UE 进程的其他 HTTP 服务也直连 —— Fab、在线登录能不能用，取决于你的网络。

`uebox doctor` 在「没有已连接的工程」这一层也会把查到的代理变量报出来，但它只看得见环境变量那一半：**它说没查到，不等于没有系统代理**。

### 导入工程时提示插件没装上

| 提示                          | 原因与处理                                               |
| ----------------------------- | -------------------------------------------------------- |
| 这个 `.uproject` 没写引擎版本 | 缺 `EngineAssociation`。用 UE 正常打开一次工程通常会补上 |
| 没有这个引擎版本的随包插件    | 引擎版本不在 5.0–5.8 范围内                              |

弹窗的主按钮是「**交给 AI 排查**」，会新开一条对话，把工程路径和原因交给 Agent 去查。也可以事后从工程卡片右键 →「安装桥接插件」。

### 更新后一批工程的插件没能更新

应用升级后所有工程同时判定过期，失败往往是一批。**先关掉虚幻编辑器**（文件占用是头号原因），再从工程卡片右键重新安装。

### 清理旧版插件失败

同样要先关闭虚幻编辑器。提示会列出没能清理的引擎。

## 项目库

### 「未找到已安装的虚幻引擎」

不一定代表没装。把引擎根目录（含 `Engine/Binaries/Win64/UnrealEditor.exe` 的那一层）拖到那块区域，或点 `+` 手动添加。

### 「读取工程列表失败」/「读取引擎列表失败」

**这次读取失败**，不代表没有工程或没装引擎。点刷新重试。

和「未找到匹配「xxx」的工程」不是一回事 —— 后者是搜索条件的问题，清空搜索框就好。

### 工程不在列表里

应用不扫描硬盘查找工程，需手动导入。点「我的项目」旁的 `+`（导入已有工程），在弹窗里选引擎最近打开过的工程，或点「选择 .uproject 文件」；也可以把 `.uproject` 或工程目录直接拖进项目库。

### 两个同名工程，侧边栏里分成了两组

这是有意的。同名工程有不同路径时，侧边栏按路径拆开，对话发往各自路径对应的编辑器。名字只出现一次时仍合并为一组。

### 模板列表是空的

模板在线上模板源里，**默认不启用就不联网**。在模板市场里启用官方源（GitHub 和国内镜像建议一起开）。

有源连不上时会说「N 个源连接失败，模板列表来自其他源」。

## 资产库

### 上传到共享库失败

先确认自己是不是只读身份。**没有写权限时上传按钮不是灰的，错误在上传时才返回。** 写权限由管理员开放。

### 「有 N 条改动待同步」

断网或服务器重启期间的正常状态。改动记在本地排队，恢复连接后自动推送。

「有改动无法同步到资产服务器，请检查冲突」是另一回事 —— 卡在版本冲突上了。

### 弹出「版本冲突」

多人修改了同一份索引。**选「覆盖远程版本」会丢弃对方的改动。**

### 「有 N 项没能存进保管库」（蓝图库 / 材质库）

**后续编辑同样存不上。** 常见原因是切换了保管库，或包目录在资源管理器里被改名、移走。处理后点「重试保存」。

### 导入卡在覆盖确认上

弹窗有倒计时，**超时按「跳过」处理**，那个文件不会导入。这是安全默认。

结束后的汇总里能看到跳过了哪些，每条标注（可重试）还是（不可重试）。

### 想重试失败的文件

在汇总中点「重试这 N 个文件」。提示「请切回原任务的保管库后重试」时需要切回原保管库；导入目标不随当前保管库变化。

### 直接往目录里放的文件库里看不到

用工具栏的「**扫描变更**」做一次增量扫描。

### 导入到工程时，目标工程显示「未打开」

模型、贴图这类文件要经 UE 转换。目标工程没开着时，按钮是「打开工程并导入」，点击后盒子替你打开工程，等 UE 连上来再自动开始导入。

- 「UE 长时间未连接到虚幻盒子」：确认工程已在 UE 里打开后重试
- 「该工程已在 UE 中打开，但未连接到虚幻盒子」：通常是 UnrealAgentLink 没启用，启用插件并重启编辑器后重试

### 导入时提示「需启用 N 个插件」

导入的资产依赖的引擎插件在目标工程里没启用，不启用的话蓝图编译会报「无效类型」「找不到函数」。点「启用插件」会写入 `.uproject`，重启编辑器后生效。列在「本机缺少」下的项，盒子无法自动启用：要装对应插件，原工程的 C++ 代码则需要连同源码一起复制并编译。

### 导入时提示「有资产版本太高」

那些资产是更高版本 UE 存的。换个工程、只导其余的，或者硬导 —— **硬导只是原样拷文件，不做版本转换，UE 里多半打不开**。

### 压缩包导不进去

应用只能解 ZIP。其他格式先用解压软件解开，再把文件夹导进资产库。

### 「打开本地路径」打不开

提示会给出具体路径。网络库的话，去保管库设置里改「浏览路径」。

## 知识库

### 检索不可用

没配「嵌入」默认模型。设置 → 模型 → 默认模型 → 嵌入。

### 答得不准

用来源面板上的「**测试知识库召回率**」，看是没召回到，还是召回到了但没用好。结果里有匹配距离和关键词命中。

### 来源送不进去

上下文有预算上限。超出时会列出本次送不进去的来源，将其降为「只给摘要」或取消勾选即可。

### 网页内容不对

切到「**查看原文**」对一下。清洗失败时应用会明说是哪一种失败，不会假装成功，见[网页清洗](/guide/notebook#网页清洗)。

## 语音与录屏

### 麦克风读不到

「无法读取麦克风，请检查设备和权限」通常是系统层面没给麦克风权限。

### 配了语音还是用不了

「实时语音」是单独一类接口，**普通对话模型不适用**。目前支持 OpenAI `gpt-realtime` 系列和豆包 Seeduplex。

### 打断不了

默认是全双工的，**直接开口就能打断**。开口也没用的话，说明这会儿退化成半双工了 —— 本地朗读一条兜底通知时，或者回声消除通路没建起来时，麦克风会被强制静音。

这两种情况下只能手动打断：点界面上的球体，或在 设置 → 快捷键 给「打断语音助手」绑一个键（默认没绑）。

### 派了活之后它一直说「开始做了」

那句话是**派发回执**，不是执行结果。语音派活是非阻塞的 —— 派完就返回，你可以接着说话。真正的结果会在做完时另外念出来。

想知道进度就问「做得怎么样了」，它会报告所有任务线的进度。见[语音通话](/guide/voice#几件活同时跑)。

### 挂断再接上，之前派的活没人交代

会交代的。接上时它先念你不在期间攒下的事（做完的、失败的、还没人答的反问），一条都没有才一个字不说。

任务本身不受挂断影响，照跑。

### 「未检测到屏幕源」

先点「刷新屏幕源」。还是没有通常是系统没给屏幕录制权限。

### 找不到录屏入口

应用的录屏是给封面用的，**侧边栏里没有入口**。从蓝图库/材质库「录制封面」或资产库详情面板触发，见[录屏与截图](/guide/small-tools)。

## 云盘

### 百度网盘授权失败

社区版不内置官方凭据，要先填自己的 AppKey 和 SecretKey。授权码**有效期 10 分钟**，过期就重新获取。

### 百度网盘传不了文件夹

从资产库右键上传这条路只支持单个文件。

### WebDAV 连不上

两种提示分别指向不同方向：「请检查服务器地址和凭据」是认证问题，「请检查网络和服务器配置」是连通性问题。

## 命令行

### 找不到 `uebox` 命令

设置 → 命令行 → 点「加入 PATH」，然后**新开一个终端**。Linux 包不带命令行工具。

### 命令连不上

```bash
uebox doctor
```

逐层报告断在哪。本机同时装了开发版和正式版时，用 `--config` 或 `UEBOX_HOST_CONFIG` 指定连哪一个。

### 写工具不在清单里

应用那头没开放写操作。`uebox doctor` 会说破。

### 退出码 7（超时）

请求可能已经到引擎，结果不明。**不要直接重发** —— 先用只读工具（如 `ue_get_actor`）确认当前状态。`ask` 超时说明它很久没有进度，不是跑得久。

### 撤销不掉

CLI 的改动**编辑器里按 `Ctrl+Z` 碰不到**。用 `uebox tools call ue_undo --args '{"steps":1}' --allow-write`（一定带 `steps`，不带会把整条撤销栈全撤）。

## MCP

### 保存按钮点不动

有配置填写不完整，提示会说「有 N 条配置填写不完整」。常见的是标识为空、标识重复、环境变量格式不对。

### 引擎工具集看不到

需要工程用 UE 5.8 或更高版本，且已连接。没有已连接工程时页面会说明。

### 开启后引擎那边没反应

「已配置 · 请重启编辑器」—— UE 没法热加载新插件模块，必须重启。

### 外部客户端突然连不上

有人点过「重置」令牌。重置后所有客户端都要重新粘贴配置。

## 应用更新

### 检查更新说连不上

两条提示指向不同方向：「暂时无法获取更新，请稍后重试」是取不到更新清单，「暂时无法连接更新服务器，请检查网络后重试」是连不上。

更新源只有公开的 GitHub Releases，没有国内镜像。

### 一直没提示有新版本

如果这个安装包**没有配置更新源**（改过那个字段而没填新的源），它连一次检查请求都不发。见[更新源](/guide/install#更新源)。

### 侧边栏左下角有更新角标但装不了

角标在版本号右边，有三种状态：「新版本」（点击开始下载）、「下载中 N%」、「重启更新」（已下载完成）。

显示「重启更新」时点它，在确认框里选「立即重启」即可，安装会重启应用。如果 AI 仍有操作没做完，会先提示「AI 仍有 N 项操作正在进行」，选「仍然重启安装」会中断它们。

## 窗口与托盘

### 点关闭按钮后应用没有退出

关闭按钮只把主窗口隐藏到系统托盘，后台任务继续运行。要退出，用托盘菜单的「退出」。AI 仍有操作没做完时，会先弹出确认框，见[系统托盘](/guide/interface#系统托盘)。

### 托盘「最近项目」点了没反应

工程已经连上盒子（标「（运行中）」）或刚点过、插件还没连上（标「（启动中）」）时，菜单项不能再点，避免开出第二个编辑器。点击后打不开会弹系统通知，写明原因：工程文件不存在、项目已在编辑器中打开，或「项目已打开，AI 连接失败」（插件没装上，点通知查看原因）。

### 开机自启关不掉

设置 → 常规 →「开机自启」默认关闭，关闭之后盒子不会再自行改回开启。如果仍然随系统启动，检查系统自己的启动项设置。

## 提问题

带上日志到 [GitHub Issues](https://github.com/ueboxai/uebox/issues)。

也可以在 AI 对话中说「抱怨一下」「记下来提给开发者」，Agent 会将本次遇到的问题写成一份缺陷报告文件，是否提交由你决定。
