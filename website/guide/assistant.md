# AI 对话

跟 Agent 对话的地方：怎么下指令、运行时能看到什么、改完怎么核对。入口是侧边栏的「AI 对话」。

![AI 对话首屏](/shots/assistant-welcome.png)

用之前先[配置模型](/guide/ai-setup)。要让它操作引擎，还需要让编辑器连上，见[连接虚幻引擎](/guide/plugin)。它能做的事见[助手能做什么](/guide/capabilities)。

## 输入框

### 斜杠命令

输入 `/` 弹出「命令与技能」菜单，`↑↓` 选择，`Enter` 调用。菜单分命令和技能两组，技能标注来源（内置 / 插件 / 用户）。

| 命令             | 作用                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------ |
| `/goal <目标>`   | 目标模式：做完后自动复核，未达成则继续改（[复核怎么跑](/guide/agent-loop#目标模式)） |
| `/team <任务>`   | 团队模式：自动组队，一路做到可玩的交付版本（见[团队模式](#团队模式)）                |
| `/image`         | 切到图片生成模式                                                                     |
| `/wiki [关键词]` | 绑定知识库；`/wiki clear` 解绑                                                       |
| `/compact`       | 压缩当前对话的历史。不在菜单里，需要手动输入；点上下文圆环效果相同                   |

`/goal`、`/team`、`/image` 生效后，输入框左侧出现对应的模式标签，点标签退出。目标模式的目标会一直显示在输入框上方，点 × 取消。运行中无法取消，需先停止。

### @ 提及来源

输入 `@` 可提及**知识库来源**和**笔记**。提及后输入框提示变为「针对 N 个来源提问...」。

### 附件

- **图片** —— 拖入或粘贴。需要模型支持「视觉」能力，或已配置「视觉」默认模型。配了[对象存储](/guide/object-storage)、模型又走 OpenAI 兼容协议时，图片传到桶里、以链接交给模型；否则压缩后直接编码进请求。
- **Excel** —— 单个文件最大 5 MB，数量有上限。
- **文档** —— 数量有上限。
- **视频、音频** —— 从文件夹拖入或用回形针选。怎么交给模型见下一节。

3D 生成和视频生成没有对应按钮，通过对话触发，见 [3D 生成](/guide/model3d#_3d-生成)。

### 视频和音频

支持的格式：

- 视频：mp4、mov、webm、mkv、avi、m4v
- 音频：mp3、wav、flac、ogg、m4a、aac、opus、aiff

从网页里直接拖过来的拿不到文件路径，先存到本地再拖。

拖进来的音视频有两种交给模型的方式，盒子按条件自动选：

|          | 模型直接看                           | 助手用工具看                                                           |
| -------- | ------------------------------------ | ---------------------------------------------------------------------- |
| 条件     | 同时满足下面三条                     | 其余情况                                                               |
| 谁来看   | 你正在对话的模型，同一轮里看完就回答 | 助手调用「分析视频」工具，交给一个勾了「视频」能力的模型看，再转述回来 |
| 追问细节 | 视频留在对话里，模型可以回头再看     | 转述里没写到的，要再调一次工具                                         |

模型直接看的三个条件：

1. 配好了[对象存储](/guide/object-storage)
2. **设置 → 模型**里，当前对话模型的「能力」勾了「**视频**」
3. 这家服务商走 **OpenAI 兼容协议**（小米 MiMo、阿里云百炼等大多数国内厂商都是）。Google Gemini 只认自家文件接口和 YouTube 的链接，所以用 Gemini 时走工具

满足时，文件拖进来就开始上传，附件卡片上显示上传进度。**不用等它传完**，直接打字、发送都行，发送时会接上这次上传，不会传第二遍。同一个文件拖第二次也不会重传。

上传失败不会拦住这条消息：它退回只给本地路径，失败原因会一起告诉模型。

::: tip 为什么要经过对象存储
多模态厂商对本地文件只收 base64 编码，上限一般在 50 MB 左右，而且编码后的视频会跟着对话每一轮重新上传一遍。换成链接，对话里只留几百字节，也不会让厂商的上下文缓存失效。
:::

**费用上要留意**：视频留在对话里，之后每一轮都会带上。模型那边每轮按视频时长和分辨率计 token；对象存储那边，厂商每读一次就是一次下行流量，100 MB 的视频聊 10 轮就可能是 1 GB。一个视频问完，开新对话接着聊别的更省。

## 对话级的三个开关

以下三项位于输入框下方，每条对话各记各的。

### Agent 模型

点击模型名，为当前对话切换 Agent 模型。任务运行期间无法切换，提示「当前任务结束后可切换 Agent 模型」。没有可用模型时显示「前往模型设置」入口。

### 思考程度

八档：`auto`、`off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。默认 `auto`。反复改不对的复杂图，可以往上调。

档位名用模型声明的原始名称，不做翻译。每个模型实际支持哪几档由模型自己声明。选了模型不支持的档位时，提示「{模型} 不支持 {所选} 档位，本次按 {实际} 执行」。

### 审批模式

控制助手改动工程之前问不问你。**默认是「帮我批准」**：助手自己往前走，识别到风险操作时才停下来。刚上手、或者工程输不起，先用「请求批准」，每次改工程都等你确认。只想让它查看分析，用「只读」。

| 档位                 | 说明                                 |
| -------------------- | ------------------------------------ |
| **只读**             | 仅查看和分析，无修改权限             |
| **请求批准**         | 修改工程和资产时始终询问             |
| **帮我批准**（默认） | 仅对检测到的风险操作请求批准         |
| **完全访问权限**     | 可不受限制地修改工程、资产和本地文件 |

审批模式每条对话各记各的：在一条对话上调紧，不会被另一条对话上的选择改回去。

::: danger 「完全访问权限」有二次确认
确认弹窗逐条列出开放的范围：

- **虚幻工程** —— 创建、修改、删除关卡中的 Actor、蓝图、材质与资产
- **文件和资产库** —— 读取、写入、移动或删除资产库中的文件
- **引擎命令与脚本** —— 执行控制台命令、运行 Python 脚本、启用或停用插件

弹窗风险提示原文：「可能导致资产被误删或工程被损坏。此设置可随时改回。」
:::

## 上下文窗口

点输入框右侧的圆环，悬停显示「上下文窗口 已用 / 总量（百分比）」，占用 80% 以上圆环变色。**点一下圆环即压缩**。

压缩把前面的历史总结成一段摘要，释放空间。用到约 85% 时自动触发，也可以手动触发。摘要保留什么、丢掉什么见[助手是怎么干活的 · 上下文与压缩](/guide/agent-loop#上下文与压缩)。

压缩完成后提示「已从 N 条压缩至 M 条，节省约 X token」。

无法压缩时的提示：

| 提示                                           | 原因                     |
| ---------------------------------------------- | ------------------------ |
| 当前对话正在处理中，请稍后再压缩               | 有一轮正在运行           |
| 历史记录较短，压缩收益有限                     | 历史长度不足             |
| 已压缩过，再次压缩只会对摘要重复概括，没有收益 | 已压缩过                 |
| 生成摘要失败，历史记录未更改                   | 摘要生成失败，历史未变更 |

## 运行过程

### 步骤摘要

两段正文之间的过程（推理和工具调用）收成一行灰字摘要，例如「读取蓝图图表、搜索蓝图节点 等 6 步」，出错的步骤会注明次数。点开后一步一行，再点一步才看到参数和返回原文。

整轮结束后，最后一段正文之前的过程收成一行「用时 · 步数」。有待回答的提问时不收。

支持推理的模型会在步骤组里显示「思考过程」。

![一轮真实对话：提问、工具调用摘要、开始作答](/shots/ai-conversation.png)

助手本轮读取过的图片默认收起，点「查看 AI 读取的图片（N）」后才加载。工具产出的截图可点开看大图。

![展开过程日志后：每一步调用了哪个工具、传了什么参数、返回了什么](/shots/ai-tool-call.png)

### 子任务

助手拆分子任务时，每一路占一张卡片，显示「子任务 N」、状态（进行中 / 已完成 / 失败）和步数。多路并行时顶部显示「N 路子任务并行中」。

点开卡片可以看到任务书，以及这一路走过的每一步：调了什么工具、对什么调的、两步之间说了什么。

子任务什么时候会被派出去，见[助手是怎么干活的 · 子任务](/guide/agent-loop#子任务)。

### 中途插话

运行期间可以直接在输入框发送消息，有两种处理方式（默认值在 设置 → AI 助手 → 运行中发送的消息，默认「完成后处理」）：

- **排队** —— 当前任务完成后处理。排队中的消息显示在输入框上方，可以「现在插话」、「撤回重新编辑」（只有文字的消息）或删除。排了多条时只显示下一条，其余收在「还有 N 条」里。
- **插话** —— 当前步骤完成后调整方向。插话可以带附件，只拖附件不打字也能发。

插话在时间线上标注「排队中 / 已发送 / 未发送」。未发送的可以「撤回重新编辑」，内容回到输入框。已提交给模型的消息无法撤回，提示「无法撤回，该消息已发送给模型」。

运行中提示「此对话仍有一轮任务在运行」时，等待其结束，或直接在输入框输入调整指令。

### 助手的提问

助手需要你决定时显示「请做出选择」卡片，提供若干选项。可以选一项、选「其他（自定义）」自己填、点「由 AI 决定」让助手选，或「关闭，暂不回答」。

多个问题时分步显示「N / M」，支持上一步和下一步。

### 操作确认

需要确认的操作弹出「**敏感操作确认**」，显示操作类型（访问网页 / 不可撤销 / 会改动工程）。按钮有四个：

| 按钮               | 效果                                                                                          |
| ------------------ | --------------------------------------------------------------------------------------------- |
| **确认执行**       | 只放行这一次                                                                                  |
| **拒绝**           | 拒绝这一次                                                                                    |
| **本对话内均允许** | 当前对话里同一个工具不再询问                                                                  |
| **以后均允许**     | 所有对话里这个工具都不再询问，记入设置，可在 设置 → AI 助手 → 已设为始终允许的操作 中逐项移除 |

「以后均允许」对只读对话无效，也不会出现在每次都要确认的操作上（见[审批门](/guide/agent-loop#审批门)）。

同时存在多条待确认项时显示「还有 N 项待确认」，逐条弹出。

::: warning 确认超过五分钟未响应按拒绝处理
提示「确认请求超时，操作已取消」。因此「需要确认时提醒」默认开启，见[通知](/guide/small-tools#通知)。
:::

## 团队模式

`/team <任务>` 把一个复杂任务交给一组分工的模型，目标是交付一个可玩的游戏版本。

| 步骤 | 谁做                             | 做什么                                                                               |
| ---- | -------------------------------- | ------------------------------------------------------------------------------------ |
| 组队 | 制作人（当前对话的模型）         | 按任务招队员，给每个队员写岗位说明、挑模型、限定可用工具                             |
| 分工 | 制作人                           | 给队员派活；队员之间、队员与制作人之间可以互发留言                                   |
| 干活 | 队员                             | 各自调用所选模型；改引擎的操作排队执行（编辑器只有一台），文档、代码、生成素材可并行 |
| 验收 | 验收员（没参与制作的独立 Agent） | 对照交付标准试玩；未通过则制作人修改后再验，受阻则停下告诉你缺什么                   |

交付标准：

- 完整的玩法循环：开始、游玩、胜负、重来
- 玩法里定义的核心机制可用
- 至少一个完整可玩的区域，美术风格一致
- 难度和成长大致合理，没有经济崩坏或死局
- 无明显缺陷：不崩溃、不卡死，蓝图和 C++ 零编译错误

做到七八成即交付，剩余的留给你打磨。

默认在新建的工程里做。目标里点名了已有工程时，会先跟你确认一次，再在里面做。

### 团队任务页签

团队模式运行时，输入框上方出现一行摘要，点它在右侧面板打开「**团队任务**」页签。

- **办公室** —— 每个队员一个小人，动作跟着实时状态变化（写、等回复、停工）。「切换画风」在像素（默认）和简约两种之间切换，两者显示同一份数据。
- **任务板** —— 一件派出去的活从开工到交回（或停下），盒子自己记账。显示「交回 N/M」、谁在忙、停下的原因。点队员查看手上的活、最近几步、往来和使用的模型；点成果展开交回的报告全文。
- **日志** —— 往来、交付、停下、编辑器崩溃与恢复，按时间排列。
- **验收结论** —— 验收通过 / 验收未过 / 验收受阻；工程在验收之后改动过则显示「改动后未重验」。

队员自行标记的完成显示为「自报完成」，盒子未核实，以验收结论为准。受阻的任务可以点「重开」，下一轮由制作人重新评估。

### 队员用的模型

制作人招人时从你配好的模型里挑，并写明理由，显示在队员旁边。只配了一个模型时没有可挑的。

点队员旁的模型标签可以更换，从该队员的下一项任务开始生效。更换前会做一次入职体检：检测连通性和工具调用能力，未通过则不更换。队员的模型不可用时，该队员暂用制作人的模型继续干。

各模型的体检结论和任务记录汇总在 **设置 → 团队**，只列出检测过或参与过任务的模型：

| 列       | 含义                     |
| -------- | ------------------------ |
| 检测     | 通过 / 未通过 / 未检测   |
| 任务     | 该模型参与的任务数       |
| 打回     | 你在任务板上重开的任务数 |
| 未完成   | 没有交回的任务数         |
| 最近使用 | 上一次参与任务的时间     |

点开一行，可以看到连通、工具调用、识图三项检测结果和「重新检测」，以及按岗位拆开的任务数、打回数、未完成数和平均耗时。

制作人招人时能读到这份履历。

### 安全网与退出

- 队员每交回一次改动了东西的活，盒子给工程存一份快照，制作人可以回滚到某一份。
- Agent 操作期间编辑器崩溃时，盒子可以关掉崩溃报告窗口、备份未保存的自动存档并重开工程，崩溃与恢复记入页签的日志。开关在 设置 → 插件 →「允许 Agent 重开崩溃的编辑器」，默认开。手动操作期间的崩溃不处理，5 分钟内再次崩溃不再重开。
- 点页签里的「结束团队模式」，对话恢复为普通对话。任务板和队员保留，下次 `/team` 可以继续。运行中需等本轮结束。

::: warning 已知限制
目标不是做游戏时（例如统计、评审），交付环节仍会要求走一遍试玩验收。
:::

## 结果核对：三层

工具返回「成功」，不等于工程里真是这样。三层依次回答三个问题：**助手说它改了什么**、**工程里现在真是这样吗**、**这是不是你要的**。

### 第一层：本轮改动

每轮回复下方列出本轮的改动，分两区：

- **引擎里的改动（N）** —— 每行格式为「[类型] 名字 [净结果]」，例如「材质 M_GlowBreath 新建」
- **引擎命令与脚本（N）** —— 控制台命令和 Python 脚本单独成区，这类操作没有对应的资产路径，按原文列出

类型包括：材质、蓝图、控件蓝图、关卡、Actor、资产、文件夹、文件、笔记、网页、插件。净结果有五种：新建、修改、删除、启用、停用。

每行可以「打开」或「在编辑器中打开」，展开后可查看该步骤的明细。

![本轮改动：建了一个材质，标着「新建」，右边是「审查」和结论](/shots/engine-changes.png)

标记含义：

| 标记         | 含义               |
| ------------ | ------------------ |
| **不可回滚** | 该步骤无法撤销     |
| **未生效**   | 该步骤未成功       |
| **N 步失败** | 明细中存在失败步骤 |

文件类的改动可点「**审查**」查看 diff。文件超过 256 KB、不是 UTF-8 文本或读不到快照时，提示「文件已写入，但无法生成对比」。

### 第二层：引擎体检

一轮结束后，如果本轮改动了 20 个以内的引擎资产且引擎在线，盒子自动对这些资产做一次体检，结论挂在「本轮改动」那一行。体检只读引擎状态，不调用模型，不消耗 token；引擎没连上或检查失败时不弹提示。

体检回答的是另一个问题：材质可能没保存到硬盘，蓝图可能编译不过。

| 结论                                     | 含义             |
| ---------------------------------------- | ---------------- |
| 报告已创建，但工程中未找到               | 未创建成功       |
| 报告已删除，但仍然存在                   | 未删除成功       |
| 修改仅存在于编辑器内存中，尚未保存到磁盘 | 需要在 UE 中保存 |
| 蓝图编译出错，当前不可用                 | 需要修复         |
| 蓝图编译有警告                           | 存在编译警告     |
| 引用了不存在的资产                       | 存在断引用       |
| 已删除，但仍被其他资产引用               | 引用方会报错     |
| 命名不符合 UE 惯例                       | 命名不符合惯例   |
| 该项检查失败                             | 检查本身失败     |

结论显示「已检查 N 个资产，未发现问题」或「发现 N 处问题」。蓝图编译出错时，结论附带引擎的报错原文，并出现「**交给 AI 修复**」，点击后把报错原文作为一条消息发给助手。

::: warning 引擎未连接时结论不完整
显示「引擎未连接，仅完成命名检查」。此时落盘、编译、断引用都没有检查，不能当作没问题。
:::

### 第三层：让它自证

点「**审查**」会先重新体检一遍，然后自动发一条请求，让助手自证。引擎没连上时，会询问是否打开工程并在连接后继续审查（「打开并审查」/「只查命名」）；仍未连接则不发自证。发出后显示「已请求 AI 自证 ↓」。

![审查结论：「已检查 1 个资产，未发现问题」，后面跟着自证的要求](/shots/engine-review.png)

体检只能核实事实（资产在不在、编译过没过），判断不了结果是不是你要的。这部分由助手逐条回应，要求如下：

1. **不许凭记忆回答** —— 每一条都要用只读工具重新到引擎中查询，写出查到的实际值。调用成功的记录不作为证据。
2. 对体检查出的每个问题，说明是真实问题还是误报；误报需给出依据。
3. 回答体检无法覆盖的部分：产出是否符合需求，哪里未做到、哪里是助手自行添加的、哪里做了折中。无法做到的直接说明。
4. **本轮只说明，不执行修改** —— 修改会改变被核实的状态。

![自证回复：做到了什么、自己加了什么、哪里做了折中、这一轮没动任何东西](/shots/engine-selfcheck.png)

## 对话管理

侧边栏的对话列表见[界面导览](/guide/interface#ai-对话列表)。

### 独立窗口

把侧边栏或标签栏里的对话拖到内容区右侧或窗口外松手，或右键选「在新窗口打开」，该对话在独立窗口里打开，主窗口里的标签随之摘除。两个窗口之间实时同步，独立窗口里可以直接使用内嵌浏览器和语音通话。

### 分支

在任意回复上选「**从这条创建分支**」，从该处复制出一条新对话，原对话不受影响，之后两边互不影响。

当前对话不支持分支时提示「此类对话不支持创建分支」。本轮尚未结束时也无法创建，提示「当前轮次尚未结束，请从更早的消息创建分支，或稍后重试」。

### 侧边问一句

「**侧边问一句（带上下文）**」打开一个携带当前上下文的小窗口，只读地问一句。

与分支的区别：分支产生一条新对话，可以继续执行任务；侧边问一句用于弄清当前状态，关闭后什么都不留下，主对话不记录这次询问。

### 其他

- 编辑已发送的消息并重新发送
- 重新生成 AI 回复（仅限 AI 回复）
- 将回复保存为笔记
- 朗读回复（需配置「语音合成」模型）
- 导出对话
- 清空对话（不可撤销）

### 发送时的编辑器快照

发送消息时应用会记录编辑器中当前选中或打开的内容，附加在该消息上。鼠标悬停显示「发送时（时间）AI 获取的编辑器状态」，内容包括当时的 Actor、资产、节点数量；未选中任何内容时显示「发送时未选中任何内容」。

## 编辑器状态监控

助手页顶栏的「状态监控」读取插件上报的编辑器状态：打开编辑器耗时、资产注册表扫描、已启用插件数、编辑器和 PIE 的卡顿率、PIE 进入耗时、本地缓存命中率与占盘、可用内存。

偏离预期的项目列在「需要注意」下，每项有「问 AI」按钮，点击后把该项数据和预期值写进输入框，请助手排查。工程里的 UnrealAgentLink 插件版本较旧时，该功能不可用，需先更新插件。

## Token 用量

每轮回复下方显示输入、输出、缓存读取、缓存写入和合计。配置了价格的模型会折算费用，按服务商的计费口径统计。

![回答末尾：token 用量、复制/重新生成/分支/朗读，以及追问建议](/shots/ai-answer.png)

完整统计在 **设置 → 用量**。

## 内置浏览器

助手访问网页时打开一块浏览器分屏，默认位于对话右侧。在 设置 → AI 助手 → 浏览器显示方式 可改为独立窗口或隐藏。

支持调整宽度、在独立窗口中打开，以及手动操作（后退、前进、刷新、停止、输入网址、多标签）。

默认不允许打开本机和局域网地址。要让助手查看本地开发服务器（如 localhost），在 设置 → AI 助手 打开「允许浏览器访问局域网」。

未配置「网页检索」服务商时使用该内置浏览器。

## 错误提示

| 提示                 | 含义                                                           |
| -------------------- | -------------------------------------------------------------- |
| 模型服务商余额不足   | 所配置的服务商返回余额不足。应用本身没有账户，不涉及应用的收费 |
| API 密钥无效或已过期 | 到 设置 → 模型 检查密钥                                        |
| 请求过于频繁         | 服务商限流                                                     |
| 服务暂时不可用       | 服务商侧异常                                                   |
| 网络连接失败         | 检查网络、VPN、代理、模型地址                                  |

连接中断或模型报错使任务中止后，回复下方出现「继续尝试」，从断点接着跑。自动重试的规则见[助手是怎么干活的 · 中断之后](/guide/agent-loop#中断之后)。原因不明确时提示「暂时无法确定具体原因，请检查模型连接后再试。」
