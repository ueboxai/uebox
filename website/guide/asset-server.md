# 资产库：服务器资产库

连接团队部署的资产服务器，在虚幻盒子里浏览、搜索、打标签，并把资产导入到 UE 工程。文件留在服务器上，本机不建库。

服务端是独立项目「虚幻盒子资产服务器」（基于 Epic 官方 Lore），由团队管理员部署，目前尚未公开发布。下面只写成员这一侧怎么用。

## 连接

**新建资产库 →「服务器资产库」**，三步：

1. **填地址**：粘贴管理员给的**邀请链接**。邀请链接里带着服务器地址、证书指纹和邀请码，会自动填好。没有邀请链接时填服务器地址，例如 `https://assets.studio.lan:8084`。
2. **登录**：三种方式，按管理员给的选一种。

   | 方式     | 填什么                                           |
   | -------- | ------------------------------------------------ |
   | 账号密码 | 成员名、密码                                     |
   | 邀请码   | 邀请码，并设置密码（至少 8 位）                  |
   | 身份令牌 | 管理员提供的令牌；加密保存在本机，过期后重新粘贴 |

3. **选库**：列出这个账号能看到的库和各自的资产数，勾选后点「添加 N 个库」。

服务器没有声明 Lore 地址时，登录页会多一个「Lore 地址」输入框（以 `lores://` 开头）。不填也能浏览，但导入和下载用不了。

### 证书

用邀请链接连接时不需要处理证书。其他情况：

- 服务器证书受系统信任：直接连接。
- 证书由团队自建的 CA 签发：填管理员给的「部署 CA 指纹」，或点「导入 CA 文件」。指纹逐字比对，不一致时拒绝连接。
- 明文 `http://` 只允许连接本机。

## 浏览与整理

- 列表按页加载。断网时显示已浏览过的页面，搜索和导入暂不可用。
- 有写权限的成员可以修改标签和备注，备注只支持一句话。
- 收藏保存在本机，在左侧「我的收藏」里查看。
- 服务端整理掉的文件，原有的标签和备注会提示「对应的文件已不在库中」，可以认领到内容相同的新文件上。

和本地库相比，下面这些暂不支持：按文件夹名搜索、按类型排序、依赖图（详情里有依赖列表）、查看回收站、标签管理、富文本备注。库的目录结构由服务端管理，不能在虚幻盒子里扫描或调整。

## 导入到 UE 工程

文件在服务器上，不能直接拖进 UE。右键资产 →「导入到工程」：

1. 选目标：工程库里的 UE 工程，或任意文件夹。`Content/…` 对应 `/Game/…`。
2. 默认「包含依赖」，会显示连同依赖共多少个资产、多大。依赖不在库里的会单独列出。
3. 点「开始」。文件通过 Lore 获取后复制到目标位置；在工程里修改副本不影响服务器。

## 上传到服务器

需要写权限。拖入文件，或在导入对话框里「选择文件」：

1. 选择要提交到的仓库，可以写一句提交说明。
2. 点「开始导入」，以你的身份提交并推送。
3. `.uasset` / `.umap` 旁边同名的 `.uexp`、`.ubulk` 会一起提交。推送完成、服务端索引完成后，文件出现在列表里。

导入和下载用的是安装包里自带的 Lore 命令行，不需要另外安装。

## 常见提示

| 提示                                   | 处理                                         |
| -------------------------------------- | -------------------------------------------- |
| 证书不受信任                           | 向管理员要邀请链接或 CA 文件                 |
| 证书指纹不匹配                         | 连到了别的服务器，确认地址后重新粘贴邀请链接 |
| 该服务器不支持账号登录，请粘贴身份令牌 | 改用「身份令牌」方式登录                     |
| 服务器库登录已失效                     | 库菜单里点「重新登录」                       |
| 该服务器未配置 Lore 地址               | 向管理员要 Lore 地址，重新登录时填上         |

## 移除

库菜单 →「从列表移除」只删除本机的连接和缓存，服务器上的库不受影响。「清空本机缓存」只清这个库的页面缓存。
