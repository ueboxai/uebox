# 资产库：入门与保管库

资产库把散在硬盘各处的素材收到一起，支持搜索、打标签、预览，并能导入 UE 工程。

Agent 也使用资产库：它从库里检索素材、导入工程，并把生成结果写回库里。

这一页讲建库和日常管理。检索和整理见[检索与整理](/guide/asset-organize)，导入工程见[导入到 UE 工程](/guide/asset-to-project)。

![资产库：左侧保管库与资产目录，中间内容区，右侧详情面板](/shots/asset-library.png)

## 保管库

资产库里可以有多个**保管库**（vault），彼此独立，各有各的文件夹结构、标签和索引。左上角的库名点开可以切换、新建、管理。

### 四种模式

新建时选一种，**建好后不能改**。

拿不准时选「**复制并归档**」：它占用磁盘，但之后移动或删除源文件夹，都不影响库里的资产。

![新建资产库：可选模式](/shots/vault-create-modal.png)

| 模式             | 做什么                                       | 什么时候选它                                        |
| ---------------- | -------------------------------------------- | --------------------------------------------------- |
| **引用原有文件** | 只建索引，不复制文件                         | 素材已整理定型、不会再移动，只想加一层检索          |
| **复制并归档**   | 把文件完整复制进库                           | 想要一份独立备份，源文件变动不影响库内              |
| **网络协作库**   | 连接局域网共享，多人协作                     | 小团队，见[团队协作](/guide/asset-team)             |
| **服务器资产库** | 连接团队的资产服务器，在线浏览，不在本机建库 | 团队长期使用，见[服务器资产库](/guide/asset-server) |

::: warning 「引用原有文件」的代价
库里存的是指向源文件的链接。源文件被移动或删除后，链接失效。**建库后不要再整理源文件夹。**
:::

::: tip 隐藏网络协作库
这一项默认开启。不想在新建对话框里看到它，可在 **设置 → 资产库 → 高级** 里关掉「启用局域网协作库」。
:::

### 读写边界

助手可以读取多个保管库，但只向当前活跃的保管库写入。切换保管库只能由用户操作，助手不会切换。

**设置 → 资产库 → 跨库搜索**：控制助手查找素材时是否搜索其他保管库。默认关闭，只搜当前保管库。开启后，搜到的其他库的资产仍需先切换到那个库，才能导入、移动或删除。

### 保管库右键菜单

在库名列表上右键一个保管库：

| 菜单项             | 说明                                         |
| ------------------ | -------------------------------------------- |
| 拉取同步           | 网络库：从服务端拉一次最新状态               |
| 更换图标           |                                              |
| 重命名资产库       | 只改显示名                                   |
| 移动位置           | 把整个库搬到另一个本地目录；网络协作库不支持 |
| 在文件管理器中打开 |                                              |
| 从列表删除         | 见下                                         |

**移动位置**对所有本地保管库（引用、复制并归档）可用，会把整个库文件夹搬到新位置。耗时可能较长，移动期间请保持应用开启，不要操作资产。目标必须是本地目录，不能是网络路径。

### 删除保管库

删除要**手动输入保管库名称**确认，输错不放行。

两类保管库的删除后果不同：

- **本地库** —— 永久删除保管库及其所有数据（文件和数据库），**不可恢复**。
- **网络协作库** —— 只移除本地的连接记录和缓存数据库，**不会删除网络位置上的源文件**。

弹窗里会写清楚当前是哪一种。

### 清除缓存

保管库菜单中的「清除缓存并重新加载」用于清除缩略图缓存，完成后报告清除数量和释放的空间。

网络库缺少写入权限时无法清除，界面提示「网络库缺少写入权限，无法清理缓存」。

## 往库里放东西

### 拖进去

文件和文件夹都支持。也可以用页面上的「添加资产」按钮选文件或选文件夹。

### 建文件夹

左侧「资产目录」区可以新建文件夹和子文件夹、重命名、删除。

文件夹名不能包含 `< > : " / \ | ? *`，`ALL` 是系统保留名。

删除文件夹时里面的内容会一起进「最近删除」，之后可以恢复。

::: danger 网络协作库里删除文件夹
共享盘上对应的目录会一并删除，团队所有成员都会失去它，**且没有「最近删除」可以恢复**。
:::

### 从虚幻直接导入

在 UE 里选中资产，可以直接导进当前保管库。界面会提示「正在从虚幻导入 N 项」，完成后报「虚幻导入完成：N 个资产」。

## 导入过程

导入分阶段进行，进度挂件上显示当前阶段：遍历中 → 预处理 → 备份中 → 入库中 →（网络库还有）上传到服务器 → 同步清单 → 写入完成。

进度挂件属于应用整体，不在资产库页面内。切换到其他页面后仍能看到进度，也可以从挂件中止导入。

### 文件已存在

弹窗问你怎么办：覆盖 / 跳过，或者「全部覆盖」「全部跳过」。

倒计时结束前不选择，按「跳过」处理，该文件不会导入。这样做是为了避免未经确认就覆盖已有文件。

### 出错了

单个文件出错时会问：取消导入 / 忽略本次 / 以后全部忽略。同样有倒计时，超时按「全部忽略」。

导入结束后给一份汇总：成功多少、失败多少、跳过多少、读取失败多少。可以展开看失败详情和跳过详情，每条会标注**（可重试）**还是**（不可重试）**。

- **重试这 N 个文件** —— 只重新执行失败的部分。源文件已移动或删除时提示「没有可重试文件」。
- 详细异常清单会写成一份 JSON 报告，可以「打开报告所在位置」。

::: warning 重试前切回原保管库
提示「请切回原任务的保管库后重试」时，需要先切回原保管库。导入目标不随当前保管库变化。
:::

### 网络库的额外一行

网络协作库导入完成后，可能显示「服务器尚未确认保存：N 项」。这表示还没收到服务端的确认回执，不是导入失败。

## 扫描外部变更

在应用之外直接向保管库目录放入文件时，库内索引不会自动更新。

点「**扫描变更**」做一次增量扫描，完成后报「发现 N 个新资产，M 个新文件夹」，或者「未发现新文件」。
