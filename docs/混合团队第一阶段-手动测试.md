# 混合团队第一阶段：手动测试

对应设计稿 `docs/混合团队设计-2026-10-24.md` 第 6 节第一阶段。制作人在 Claude Code，队员在盒子里跑，不需要 Unreal 工程。

## 准备

1. 在这个分支上跑 dev 盒子。worktree 里没有 `node_modules`，要借主检出的：

   ```powershell
   $env:PATH = "H:\UnrealAgent\uebox-pub\node_modules\.bin;" + $env:PATH
   pnpm dev
   ```

   dev 盒子用的是正式版同一份用户数据，先关掉正式版。
2. 设置 → AI：至少两个对话模型（招人才出 `model` 参数），比赛用的那几个要配好。
3. 设置 → 对外 MCP 服务：打开，允许写操作，记下端口（默认 17861）和令牌。
4. Claude Code 工作目录下的 `.mcp.json`：

   ```json
   {
     "mcpServers": {
       "uebox-producer": {
         "type": "http",
         "url": "http://127.0.0.1:17861/",
         "headers": {
           "Authorization": "Bearer <令牌>",
           "X-Unreal-Box-Profile": "producer"
         },
         "timeout": 660000
       }
     }
   }
   ```

   - `timeout` 必须调大：Claude Code 对 HTTP 的 MCP 请求默认 60 秒就超时（也可以设环境变量 `MCP_TOOL_TIMEOUT=660000`）。
   - Claude Code 对 HTTP 调用另有 5 分钟「没动静就掐」（`CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT`）。`team_wait` 默认等 280 秒、`team_send` 带 `wait: true` 最多等 280 秒，就是为了躲它；想一次等满 600 秒，把这个变量也设成 660000。
   - 不要同时加载完整的盒子 MCP 连接（`claude-plugin-mcp`）。
5. 用 Fable 打开 Claude Code，`/mcp` 里应只有 12 个 `team_*` 工具。

## 里程碑

| 步骤 | 让 Fable 做 | 期望 |
|---|---|---|
| 1 | `team_open`，给一句目标 | 回话里有 team_seat、混合版须知（提 `team_wait`，不提 `team_deliver`）和可招的模型名单 |
| 2 | `team_hire` 招「策划」，`model` 填 DeepSeek V4.1 Flash 的 id，写 `model_reason` | 过入职体检（30 天内体检过的直接用结论）；任务板上卡片显示模型名，悬停看到理由 |
| 3 | `team_send` 派「写设计文档，并在任务板上放 3 个任务」，然后 `team_wait` | `team_send` 立刻回；任务板显示运行中和动态；`team_wait` 拿到【交活】和写操作记录；工作区有文档，任务板有 3 项；用量有 token 数 |
| 4 | 再派一件只有记得第一件才答得出的活 | 答得出 |
| 5 | 派一件分几步的活，跑着的时候 `team_message` 给它改要求 | `team_message` 回「正在干活，已插进它的下一步」；交回的结论按新要求改了 |
| 6 | 盒子「外部团队」页 | 没有「Claude Code 驱动」标签；有模型、成果、用量、往来、运行中 |
| 7 | 在外部团队页点「结束团队模式」 | 正在跑的活收成「停下」；之后制作人再调工具报「已经结束了」 |
