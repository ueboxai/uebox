# 团队任务板可读性改版（2026-10-14）

范围：「团队任务」页签里办公室**下面**的部分。办公室本身不动。

## 一句话

用户派团队去干活，想知道三件事：**干完没有、交回了什么、谁在忙**。
旧版把这三件事拆在「成员 / 任务 / 留言」三块里，三块数据来自三本对不上的账，只能靠用户自己拼。
新版把它们合成一本「活的账」：一件派出去的活，从开工到交回（或停下），盒子自己记。
界面围绕这本账来画。

## 旧版为什么难读（真机 2026-10-14，「派多个员工统计项目信息」）

1. **页头答错「干完没有」**：上一轮的「验收通过」一直挂着，下面却有人在「正在搜索」。
   只读的活不改工程，所以这块牌子永远不会过期。
2. **交付没进任务**：任务板全靠制作人记得去写。所以出现交了报告却没有任务、在干活却名下没有任务的情况。
3. **默认派活方式交回的报告不落盘**：等队员干完的那种派活，报告直接回到制作人，界面上看不到。
4. **报告埋在留言底部**：报告和寒暄用同一种卡片，按时间倒序排，最早交的报告沉到最下面。
5. **一条提醒拆成两张卡**：同一段话群发给两个人，界面上就是两张一样的卡。

## 新版

两种画风读同一份数据（`teamBoardModel.ts`），只是画法不同。不跳页、不弹层，点了就在原地展开。

### 像素画风：委托板（`teamQuest/TeamQuestBoard.vue`）

和像素办公室是同一个世界：深木色的游戏界面，缺角像素边框，点阵标题。

| | 默认可见 | 点了才出现 |
|---|---|---|
| 委托 | 目标、此刻状态（安排中 / 进行中 / N 件活停下了 / 本轮完成 / 待命）、一件活一格的进度、本轮验收章 | 进度格悬停看是哪件活 |
| 队员 | 每人一张角色卡：办公室里同一个小人（干活在写、等回复在说话、停下了捂脸、刚交完举手、闲久了打瞌睡），头顶气泡说此刻在干嘛，右上角是交回几份 | 点卡片：在**这一行下面**插一块详情（小三角指着卡片），里面是手上的活、最近几步、往来、模型、名下任务板项（受阻的能重开） |
| 成果 | 这一轮的活：交回的是卷轴（新交的带 NEW），在写的是虚线空格加爬行进度条，停下的是撕开的卷轴 | 点卷轴：在这一行下面展开一张羊皮纸，先显示前几段，点「展开全文」看完整报告，点「卷起」收回；更早几轮交回的成果收在折叠里 |
| 任务板 | 一行：几项，以及受阻几项 | 展开后是便利贴颜色的清单，受阻的能重开 |
| 日志 | 最新一条 | 展开全部：往来、交付、停下、崩溃、恢复、验收，按时间排列；交付那条点一下就展开对应的卷轴 |

### 简约画风：泳道（`teamLanes/TeamLaneBoard.vue`）

跟着主题走，和简约版办公室一致。

| | 默认可见 | 点了才出现 |
|---|---|---|
| 一句话 | 状态、几人在干活、交回几份、本轮验收、目标 | — |
| 泳道 | 一人一条：此刻在干嘛，以及一条时间轴（色条是一件活从开工到交回，菱形是交付，叉是停下，红色虚线是编辑器崩溃） | 点一条：手上的活、交回的成果（标题，点开看前几段，再点看全文）、最近几步、往来、模型；点菱形直接展开那份成果 |
| 尾部 | 「更早的成果 N 份」「任务板 N 项」两行折叠 | 展开 |

### 两种画风共用的规则

- **验收牌只说这一轮**：验收时间晚于本轮开始、并且没人在跑时才显示。工程改过之后显示「改动后未重验」。
- **状态以活的账为准**：最近一件交回了，就说交了什么；停下了，就说停在哪；停下之后又派了一件并交回来，就不再算停着。
- **往来里不重复交付**：交付在成果里，往来只放说的话和崩溃。同一个人连着把一模一样的话发给几个人，合成一条。
- **崩溃是全队的事件**：画成一条贯穿所有人的线，并出现在当时手上有活的人的往来里，而不是变成几张一样的留言卡。

## 数据

- `TeamJob`（`shared/agentTeam.ts`）：一件活的开工、交回或停下、报告原文、停下的原因。
  在 `teamTools.ts` 的 `assign` 里记账，两种派活方式都记，排队的活轮到它开工才算开始。
  落盘在 `<会话>.team/jobs.json`，最多留 200 条。
- `TeamEvent`：编辑器崩溃、恢复、恢复失败。`ipc/agentV3.ts` 的编辑器看护记账，落盘在 `events.json`。
- 新一次运行开始时（`prepareTeam`），账上还挂着「在干」的活一律收成停下：上次运行被打断的活不会再交回来。
- 老数据没有活的账：拿后台派活留下的【交活】【没干完】留言补成交回的活。

## 不在这次范围内

- 统计、评审这类不产出游戏的目标，交付闸仍然会推制作人去走试玩验收（`teamSession.ts` 的 `createTeamGate`）。
- 寒暄类留言不做识别和隐藏。往来默认收着，就不再占首屏，也就不需要编关键词去判断。
- 点阵中文只用在标题和印章上（`teamQuest/PixelLabel.vue`：用系统字体按小字号画，再二值化放大），不打包点阵字库。正文仍用系统字体。
