# 音效生成（generate_sound_effect）设计

2026-10-16 · 已实现

## 一句话

让 Agent 按一句描述出**可直接拖进 UE 的 WAV 音效**：脚步、点击、爆炸、风声循环。绑了 ElevenLabs 就云端生成写实音效；没绑也能用 —— Agent 拿本机 FFmpeg 合成合成器类音效，免费、不要密钥。

## 为什么要做

- UE 开发者要音效比要配乐多得多，一个关卡几十个短音效，配乐只要几首。
- 以前 Agent 被问「做个开门声」只能说做不了，或者拿配乐工具硬凑（最短 3 秒、强制纯音乐）。

## 用户怎么用

1. 什么都不配：说「做个按钮点击音效」，Agent 用本机 FFmpeg 合成。没装 FFmpeg 时，Agent 会告诉用户两条路：装 FFmpeg，或者配 ElevenLabs。
2. 要写实音效：偏好设置 → 模型来源 → 添加服务商 →「音频与 3D」页 → ElevenLabs 音效，再在默认模型里把「音效生成」绑上它。
3. 生成的文件在对话里直接能试听；云端生成的同时存进素材库 AIGC/音效。说「放进工程」就走 `ue_content_import`。

## 两条路怎么分

只有一个入口工具 `generate_sound_effect`。它按「音效生成」角色绑没绑来分路：

| 状态 | 工具做什么 | 返回 |
|---|---|---|
| 绑了 ElevenLabs | 按变体逐个生成 WAV，存进素材库 | `mode: cloud`, `tracks[]` |
| 没绑 | 不出声，只探测本机 FFmpeg | `mode: local`, `ffmpeg`（路径或 null）, `outputDir` |
| 绑了 Box Plan | 报错：网关没有音效接口 | — |

本地那条路由 `sound-effects` 技能接手：技能里有现成的 FFmpeg 配方（点击、提示音、金币、激光、呼啸、脚步、爆炸、无缝循环）、两遍法峰值归一化、测量命令，Agent 用 `run_shell_command` 执行。这些配方都在 Git Bash + FFmpeg 7.1 下原样跑过。

没绑也能用，和「网页检索」不绑就用内置浏览器是一个思路，所以不另设「本地」服务商。

## 实现

- **角色 / 类型**：`ProviderKind` 和 `ModelRole` 都加 `sfx`，不回落到别的角色。设置页「音效生成」那行带 `?` 说明，**不进**「未配置就不可用」的红字名单（空着也能用）。
- **目录**：`elevenlabs-sfx`，模型 `eleven_text_to_sound_v2`，环境变量和 ElevenLabs Music 一样是 `ELEVENLABS_API_KEY`。目录分页「音乐与 3D」改名「音频与 3D」。
- **接口**（`src/main/ai/soundEffect.ts`）：`POST /sound-generation?output_format=pcm_44100`，请求体 `{ text, model_id, loop, duration_seconds? }`。44.1 kHz PCM 要 Pro 档账号，被 4xx 拒收就降到 22.05 kHz 再要一次。PCM 套 WAV 头（`wavBytes`，和配音共用），因为 UE 不导入 MP3、本机也不一定有 FFmpeg 转码。
- **防重复扣费**：这个接口是同步的，没有任务号可以续查。提交前先用 `wx` 写回执；回执在、文件不在就报「上次结果未确认」，不自动重交，回执路径写进报错。全部 4xx（408/429 除外）删回执、允许重试。没有照设计初稿去抽 `music.ts` 的公共逻辑 —— 那边是异步任务三段式，这边几十行就够。
- **变体**：`variants` 1–4，变体编号写进回执哈希，同一描述的几个版本各是各的文件。
- **入库**：`AIGCAssetType` 加 `sound`（文件夹「音效」，分类「AI 音效」）。`saveLocalMusicAsset` 多一个 `assetType` 参数，两种类型共用。
- **分组**：`aigc` 组，按需加载，不占常驻预算。检索词加 `音效 声音 sound effect sfx`。技能正文点了 `generate_sound_effect` / `run_shell_command` / `ue_content_import`，`load_skill` 时这几组一并带上。
- **对话里试听**：`collectGeneratedMusic` 认 `generate_sound_effect` 的 `tracks`。本地合成的文件靠 Agent 在回复里给本地链接。

## 先不做的

- **`inspect_audio`**：听感靠人。技能里让 Agent 只量时长、峰值、RMS 这些机器事实，然后明说「我听不到，请你试听」。
- **Box Plan 音效**：网关没有接口也没有定价。
- **本地合成的文件入素材库**：现在只落在 `Music/UnrealBox/sfx`。用户要的话再接。
- **配乐工具改名**：`generate_task_music` 会破坏外部 MCP 调用方，等 breaking 版本一起改。

## 没验证的

- 没有 ElevenLabs 密钥，云端那条只靠单测（按官方文档的请求形状 mock）。第一次真实调用要人看一眼：采样率回落、loop 参数、计费和预期是否一致。
- 本地配方的听感没人听过，只量过数（峰值、RMS、时长、循环接缝前后 RMS 一致）。
