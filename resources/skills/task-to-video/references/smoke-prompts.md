# 验收用例

| 输入与环境 | 预期 |
|---|---|
| “把刚才做材质的过程做成一分钟教程” | 触发；读取当前对话完整快照；真实成果优先；输出 MP4 与分镜 |
| “把这些成果做个宣传片，缺背景可以补” | 触发；允许必要补图；不批量生成昂贵视频 |
| “来个整活视频”且当前任务有明显反差 | 触发；围绕任务创作文案，不伪造用户原话 |
| “生成一段猫跳舞的视频”且无任务回顾意图 | 不触发，属于独立 AI 视频生成 |
| “分析这段视频” | 不触发，属于视频分析 |
| “生成一首周末午后听的 lofi 纯音乐” | 不触发视频技能；直接调用 generate_task_music，省略 projectDir，不整理视频素材、不检查 FFmpeg |
| “用 Sequencer 渲染这个镜头” | 不触发，属于引擎渲染 |
| “教程”但没有明确视频意图 | 澄清是否要视频；不自动生成收费素材 |
| 没配语音、音乐 | 成片有字幕，无配音配乐，不擅自挑来源 |
| 已配语音但接口失败 | 明确失败，保留工程；提供重试或无配音继续 |
| 历史截图过期 | 取快照中的可用图片或按任务补素材，不谎称拿到了旧截图 |
| 必须靠 AI 视频表达的创意镜头 | 给出少量短镜头备选和费用不确定性，接受后调用 |
| “只用现有素材，别花钱” | 不调用生图、视频、音乐、配音等收费服务，保留字幕 |
| “把第二段字幕改一下” | 复用原工程和音频，只修改对应文案；旧版本仍在 |
| Mureka 提交成功后断网 | 同参数继续查询已有任务，不再次提交 |
| SUNO 提交成功后断网或取消等待 | 同参数恢复已有任务查询，不重复提交，不下载尚未完成的流式音频 |
| SUNO / Mureka 一次返回多首 | 全部保存并交付；下载中断只补缺失曲目，不重新付费生成 |
| SUNO 未配置回调地址 | 自动填入占位回调字段，保存任务编号后轮询，不要求用户搭服务器 |
| 没有 FFmpeg | 首次准备阶段说明缺口，不先花钱生成素材 |
| “这段稿子一个字不改，控制在 15 秒”但原文明显过长 | 不擅自删稿或截断旁白；说明冲突并给出保留原文 / 允许精简的选择 |
| 已有配乐成片，用户说“不要旁白，音乐保留” | 只关闭配音，保留原音乐路径，不重新生成音乐 |
| 已有有声成片，用户说“改成完全静音” | 关闭配音并移除原音乐路径，保留字幕 |
| “只去掉配乐” | 移除音乐路径，保留已有配音与音色 |
| 教学旁白连续解释三个不同操作 | 拆成与讲解对应的真实画面，不用一张总览图撑完整段；关键参数画面保持稳定 |
| 宣传片混用已有成果与补图 | 主体与风格一致；演示能看出操作和结果；不虚构收尾链接 |
| 只查看了镜头预览图 | 只报告静态布局检查，不能宣称转场和声音已验收 |
